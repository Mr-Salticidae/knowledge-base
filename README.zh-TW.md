這是跳蛛先生 / Mr. Jumping Spider 的 AIGC 創作方法論公開知識庫，記錄 AI 圖像、影片、音樂創作、角色一致性、覆盤機制，以及人機協作工作流程中可重複使用的洞見。

適合這些讀者：

- 正在做 AI 圖像／影片／音樂創作的人；
- 想研究 Midjourney、Suno、可靈、Seedance、Claude 等工具協作邊界的人；
- 想用 Obsidian 管理創作方法論的人；
- 對「創作者判斷 + AI 執行」工作流程有興趣的同好。

本儲存庫公開的是**方法論與程式碼範例，不是素材包**。筆記中出現的 `{AIGC工作站}`、`项目工作区/` 等路徑都是作者本機工作區的佔位符，用來說明來源與脈絡，讀者不需要有相同的目錄。

展示網站 [蛛网之上（Above the Web）](https://tiaozhuxiansheng.com) 由本儲存庫建置而成（僅簡體中文）。

## 這是什麼

每次創作探索之後，把**有洞見的發現**沉澱到這裡，累積成可長期重複使用的資產。

這不是產出歸檔，**而是洞見歸檔**——圖片、音訊、影片等素材本身通常不在本儲存庫，這裡只存「我學到了什麼」。

本目錄是一個 **Obsidian Vault**（設定見 `.obsidian/`）。所有筆記之間用 `[[雙向連結]]` 互相串連，既能點擊跳轉，也能在 Obsidian 的關係圖譜裡看到知識脈絡。

## 怎麼使用這個知識庫

1. **在 GitHub 上瀏覽**，從下方知識地圖開始：每個資料夾都連到列出全部內容的索引。
2. **在 Obsidian 裡閱讀**，把儲存庫 clone 下來、以 Vault 開啟資料夾。[README.md](README.md) 是入口地圖（MOC），按 `Ctrl+G` 開啟關係圖譜。
3. **順著連結走**：每篇筆記底部的 `关联文档`（關聯文件）段落，就是通往下一個想法的入口。

## 五條核心規則

1. **沒有洞見就不寫**：不是每次探索都必須沉澱
2. **更新優先於建立**：先看既有筆記能不能補內容，再決定新建
3. **每篇筆記都有「如何使用」與「關聯文件」段落**：前者讓它成為工具，後者讓它在圖譜裡不成孤島
4. **引用主作品，而非複製**
5. **只在一處登記**：完整清單放在各資料夾索引，README 只做導覽、只收樞紐筆記；不寫按日期的流水帳，git 歷史就是流水帳
