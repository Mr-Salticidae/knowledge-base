これは跳蛛先生 / Mr. Jumping Spider による、AIGC 創作方法論の公開ナレッジベースです。AI による画像・動画・音楽制作、キャラクターの一貫性、振り返り（復盤）の仕組み、人と AI の協働ワークフローから得た、再利用できる知見を記録しています。

こんな方に向いています：

- AI で画像・動画・音楽を作っている方
- Midjourney、Suno、可灵（Kling）、Seedance、Claude などのツールを組み合わせるときの得意・不得意を研究したい方
- Obsidian で創作の方法論を管理したい方
- 「判断はクリエイター、実行は AI」というワークフローに関心のある方

ここで公開しているのは**方法論とコードサンプルであり、素材集ではありません**。ノート中の `{AIGC工作站}` や `项目工作区/` といったパスは、作者のローカル作業環境を指すプレースホルダーです。出どころと文脈を示すためのもので、同じフォルダ構成を用意する必要はありません。

ショーケースサイト [蛛网之上（Above the Web）](https://tiaozhuxiansheng.com) はこのリポジトリから構築されています（中国語のみ）。

## これは何か

創作の探索を終えるたびに、**知見のある発見**をここに蓄積し、長期的に再利用できる資産にしています。

**成果物のアーカイブではなく、知見のアーカイブ**です。画像・音声・動画などの素材そのものは基本的にこのリポジトリには置かず、「何を学んだか」だけを残しています。

このリポジトリは **Obsidian の Vault**（設定は `.obsidian/`）です。ノート同士は `[[ウィキリンク]]` でつながっており、クリックでたどることも、Obsidian のグラフビューで知識のつながりを眺めることもできます。

## 中国語が読めない方へ

- **ブラウザの翻訳機能**：GitHub 上の本文はブラウザ翻訳でかなり読めます。ファイル名やリンクは中国語のままです。
- **LLM で翻訳**：ほとんどのノートは単体で完結しているので、ノートを丸ごと LLM に貼り付けて翻訳させることができます。
- **プロンプト**：ノート内の Midjourney 用プロンプトの多くは英語なので、そのまま使えます。可灵・即梦など中国語優先のツール向けプロンプトは、通常中国語です。
- **ノートの構成**：多くのノートは `一句话总结`（一行まとめ）で始まり、`如何使用`（使い方）を含み、末尾に `关联文档`（関連ドキュメント）があります。

## 使い方

1. **GitHub で読む場合**は、下のナレッジマップから始めてください。各フォルダは、中身をすべて載せた索引にリンクしています。
2. **Obsidian で読む場合**は、リポジトリをクローンしてフォルダを Vault として開きます。[README.md](README.md) が入口のマップ（MOC）です。`Ctrl+G` でグラフビューを開けます。
3. **リンクをたどる**：各ノート末尾の `关联文档`（関連ドキュメント）が次のアイデアへの入口です。

## 5 つの基本ルール

1. **知見がなければ書かない。** すべての探索を記録する必要はない
2. **新規作成より更新を優先する。** まず既存のノートに追記できないかを確かめる
3. **どのノートにも「使い方」と「関連ドキュメント」を置く。** 前者はそれを道具にし、後者はグラフ上で孤島にしない
4. **元の作品は引用し、コピーしない**
5. **登録は一か所で。** 完全な一覧は各フォルダの索引に置き、README は案内とハブノートだけを担う。日付ごとの更新履歴は書かない（git の履歴がそれにあたる）

## コントリビューション

プルリクエストを歓迎します。すべての PR で自動のコンプライアンスチェックが走り、他のマシンの絶対パス、索引の列ずれ、ウィキリンクや frontmatter の問題を検出します。他マシンのパスはチェック失敗、それ以外はヒント扱いで、いずれもレビュー前の警告であってマージを止めるものではありません。その後、メンテナが [PR レビューチェックリスト](00_仓库维护/外来提交PR审核清单.md)（中国語）に沿ってレビューします。

新しいノートは[執筆規約](00_仓库维护/知识库写作规范.md)（中国語）に従います：ファイルの命名、frontmatter の `类型/…` タグは 1 つだけ、`关联文档` セクション、所属フォルダの索引への登録。
