这是跳蛛先生 / Mr. Jumping Spider 的 AIGC 创作方法论公开知识库,记录 AI 图像、视频、音乐、角色一致性、复盘机制和人机协作工作流中的可复用 insight。

本仓库公开的是**方法论与代码样例**,不是素材包。文档中出现的 `{AIGC工作站}`、`项目工作区/` 等路径均为本地工作区占位,用于说明来源和上下文,不要求读者具备相同目录。

## 这是什么

每次创作探索后,把**有 insight 的发现**沉淀到这里,形成可复用的长期资产。不是产出归档,**是 insight 归档**:图、音频、视频等素材本身通常不在本仓库,这里只存"我学到了什么"。

本目录是一个 **Obsidian Vault**(配置见 `.obsidian/`),文档之间用 `[[双链]]` 互相连接,既能点击跳转,也能在关系图谱里看到知识脉络。

## 怎么用

1. **按目录找**:下面的知识地图每个目录一段,先进目录索引,再到具体文档。
2. **沿双链走**:每篇文档底部的「关联文档」是下一站入口。
3. **看图谱**:Obsidian 里按 `Ctrl+G`,颜色代表文档类型(见 [[知识库写作规范]] §5)。
4. **写之前先搜**:`Ctrl+O` 模糊搜一遍,能加补丁就别建新文件。

├── README.md          本页:导航入口

- 每个目录都有自己的索引(`xx索引.md`),是该目录的完整清单。

- 多语言译本是稳定导览页,不逐条镜像本页;只有新增 / 撤销目录、目录结构变化、许可或贡献流程变化、译本里列出的入口文档改名时才需同步,改完更新译本顶部的「最后同步」日期。译本已在 `.obsidian/app.json` 里排除,不进图谱和搜索。
