# 知识库写作规范

> 入档:2026-09-25(由根目录 README 的颜色规范 / 链接规范 / 何时更新 / 核心规则合并而来,并补上命名与登记规则)
> 适用范围:01–05、09 的知识笔记。`07_skill存档/` 是原文归档,不按本规范改写;`08_对外分发/` 只遵守命名规则。

---

## 1 · 五条核心规则

1. **没 insight 就不写**:不是每次探索都必须沉淀。
2. **更新优先于创建**:先看现有文档能不能加补丁,再新建。
3. **每篇都有「如何使用」和「关联文档」**:前者让它成为工具,后者让它在图谱里不成孤岛。
4. **引用原作,不复制**。
5. **一处登记**:完整清单只在各目录索引里维护;根目录 README 只做导航,只收枢纽文档。不写日期流水账,git 历史就是流水账。

---

## 2 · 放在哪儿

| 内容 | 位置 |
|---|---|
| 新 sref 编号 | `01_sref档案/`,文末链回 [[sref编号独立律_v1]] |
| 旧 sref 的新行为 | 在原档案加补丁,不新建 |
| 参数 / 模型的实测规律 | `02_参数行为档案/` |
| 可复用的 prompt 段、基础句 | `03_prompt模板库/01_prompt模板/` |
| 作品 / 比赛 / 获奖图复盘 | `03_prompt模板库/02_案例复盘/` |
| 素材准备、交接、流程规范 | `03_prompt模板库/03_流程规范/` |
| 反直觉或有思辨深度的发现 | `04_方法论与洞察/` 下最贴近的子目录,不要平铺在根 |
| IP 视觉沉淀 | `05_视觉系统/` |
| 代码镜像 | `06_代码/` |
| 测试过的 skill 原文 | `07_skill存档/` |
| 面向读者、可直接转发的独立稿 | `08_对外分发/`(正文不写双链) |
| 展示站与平台的工程经验 | `09_平台工程/` |
| 仓库维护记录 | `00_仓库维护/` |
| 纯欣赏、没有 insight 的图 | 不入库 |

**新增一篇之后:**

1. 在所属目录的索引里登记一行(`xx索引.md`)。
2. 在文末「关联文档」写双链,并给被链接的文档补反向链接。
3. 只有枢纽级(⭐⭐ 以上,或被多处引用的入口方法论)才同时加进根目录 [[README]] 的对应目录下。

## 3 · 命名

- **字符**:只用中英文、数字、`_`、`-`、`+`、`.`;不用空格、括号、`&`。
- **全局唯一**:Obsidian 按文件名解析双链,不同目录也不能重名。
- **结构**:核心概念名 + 限定词,例如 `seed_行为规律_v1`、`personalize与moodboard分工_v1`。
- **版本后缀**:知识笔记以 `_vN` 结尾,新建默认 `_v1`;大改升版时改文件名并同步引用。持续滚动更新的「活合集」例外。
- **复盘**:以日期开头,`YYYY-MM-DD_主题_复盘_v1`。
- **sref 档案**:`sref_编号_描述_v1`。
- **不加版本号**:目录索引(`xx索引.md`)、说明文档(`xx说明.md`)、维护文档、对外分发稿。
- **README**:全库只有根目录一份(外加 `README.<语言代码>.md` 译本)。子目录的目录说明用 `{业务名}索引.md` 或 `{业务名}说明.md`。

## 4 · 文档格式

```markdown
---
tags: [类型/核心方法论]
---
# 标题

> 入档:2026-09-25
> 来源:...

## 一句话
...

## 如何使用
...

## 关联文档

- 顶层方法论:[[角色一致性金字塔_v1]]
```

- **frontmatter**:`---` 顶到文件第一行,前面不能有空行或 BOM;只挂**一个** `类型/` 标签。
- **H1**:纯标题,不加「笔记 ·」「复盘 ·」之类的类型前缀,不写版本号(版本号只在文件名里)。
- **元信息**:H1 下第一行写 `> 入档:YYYY-MM-DD`,其余元信息按需追加。
- **结尾段**:统一叫「关联文档」,不用「关联」「双链」「七、关联文档」等变体。

## 6 · 链接

| 写法 | 效果 |
|---|---|
| `[[文件名]]` | 跳转到该文档 |
| `[[文件名\|显示文字]]` | 显示别的文字,点击同样跳转 |
| `[[文件名#二级标题]]` | 跳到该文档的某个标题 |
| `![[文件名]]` | 嵌入该文档的全部内容 |

- **不带 `.md`**:写 `[[角色一致性金字塔_v1]]`,双链里不加后缀。skill 例外,写 `[[skill名/SKILL.md]]`。
- **方向**:卫星(档案、复盘)链回枢纽(顶层方法论);枢纽列出典型例证;同层方法论互链。
- **库外引用写裸路径**:`{AIGC工作站}/xxx`,不要塞进 `[[]]`(Obsidian 链接只在 Vault 内有效)。
- **代码文件写路径**:`06_代码/断裂网格海报模板/make_poster.py`。
- **占位链接**:只用于确定要写的文档,并登记在 README 的「待写」清单里;写不出来就改回纯文本,不要长期挂灰链接。
