# 多平台同步投稿:发布页字段与浏览器辅助清单

> 入档:2026-09-26
> 来源:76_清月 发布(9:16 / 15 秒 AI 短片),B站 → 抖音 → 快手 → 视频号依次投稿;助手用 Claude in Chrome 填表,作者上传视频、登录、点发布
> 验证状态:⚠️ B站/抖音/快手两次(2026-09-26 竖版、2026-10-01 横版),视频号一次,小红书一次(2026-10-01);平台改版后字段位置可能变
> 2026-10-01 补:71_余温 见证者角色 PV(16:9 / 38 秒)B站 → 抖音 → 快手 → 小红书,见下方「2026-10-01 补丁」
> 2026-10-14 补:84_那道题还亮着 MV 六平台(加即梦、视频号);**小红书不能带任何其他平台信息**(余温先导片因此被限流),见「2026-10-14 补丁」

## 一句话

同一条竖版母版发四个平台,**要准备的封面比例不一样**:B站要 4:3 和 16:9 两张,抖音要竖 3:4 和横 4:3 两张,快手、视频号各一张 3:4。每个平台的 AI 声明在不同位置,叫法也不同。助手能填的都填好,**停在发布按钮前**,由作者审完自己点。

## 如何使用

### 开工前准备(一次做完,各平台共用)

- 成片母版(原版,不压缩)。
- 封面三张:**3:4 竖版**、**16:9 横版**、**4:3 横版**。4:3 从 16:9 本地无损裁出即可,不用另外出图。
- 每个平台一段文案(标题 / 简介 / 话题),事先写进一个文件,便于核对。

### 分工

| 作者 | 助手 |
|---|---|
| 登录(扫码)、上传视频文件、点「发布 / 投稿」 | 填标题、简介、话题 / 标签,传封面,选分区,勾 AI 声明,最后列出已填内容和没动的默认项 |

- 视频由作者传,理由不只是体积上限,见 [[浏览器插件自动化的能力边界_v1]] 的 2026-09-26 补丁:**不要为了能自动上传而压缩母版**。
- 作者传完视频,把那个标签页拖进 Claude 的标签组,助手再接手。也可以反过来:助手先在自己的标签组里打开发布页,作者直接在那个标签页里传(视频号就是这样做的)。
- **上传视频和填表不要同时进行。**视频号那次作者上传的同时助手在填,页面一重排,点击就落错了框。

### 四个平台的字段(2026-09-26 实测)

| | B站 | 抖音 | 快手 | 视频号 |
|---|---|---|---|---|
| 标题 | 独立标题栏,≤80 字 | 独立标题栏,≤30 字 | **没有标题栏**,标题和描述合写进「作品描述」 | 可选的「短标题」栏 |
| 简介 / 描述 | 独立简介框 | 独立简介框,话题也在这里 | 「作品描述」一个框 | 「视频描述」一个框 |
| 话题 / 标签 | 标签单独一栏,回车成签;**会自动预填无关标签**(这次是「直播、生活记录、记录」),要删掉 | 输 `#` 后从候选里点选,变蓝才是正式话题 | 同抖音;候选里没有的可以手打 | 没有候选框:直接打 `#词`,**后面跟一个空格**才变成正式话题 |
| 封面 | **4:3「首页推荐」+ 16:9「个人空间」两格**;另有可选的 PK 封面(A/B 测试用) | **竖封面 3:4 + 横封面 4:3 两个页签**;有封面检测 | 一张,从上传页签传 3:4 原图 | 一张 3:4(个人主页和分享卡片)。视频传完才出现「封面预览 → 编辑 → 上传封面」 |

| 分区 | 要手动改;这次被自动选成「影视」,改成「动画」 | — | — | — |
| 默认开着、要作者决定的 | 定时发布、合集、商业推广、转载授权 | **「同时发布到」今日头条 / 番茄小说**(账号记住的设置) | 允许跟拍同框、允许下载、同城页展示 | **位置默认按网络定位填好(这次是「深圳市」),发表后公开**;声明原创默认不勾 |
| 陷阱 | 标签输入框回车后会失焦,每个标签前重新点一次 | **话题候选旁边就是官方活动卡片**,点偏会把活动插进简介(这次误加了一个,已删) | 候选里的近似话题(「#国风仙」「#aigc」)不是要的那个,别顺手选 | **视频一传完,表单顶部插入「封面预览」一行、整张表单下移**,之前定好的坐标全部失效(这次短标题被打进了描述框);表单在微前端 shadow DOM 里,扩展的元素定位看不到,见下一节第 7 条 |

### 填表时的做法

1. 每个平台开始前先截一张全页图,看清各个上传位分别对应什么比例。
2. 页面里常有好几个隐藏的文件框。先用 JS 给每个 `<input type=file>` 标上名字再定位,传完切回另一个页签确认没传错位置。
3. 富文本框别用 `Ctrl+A`,会选中整页;点进框里再清空。
4. 选话题和候选项用元素定位,不要靠坐标点(抖音那次误点就是坐标偏了)。
5. 填完用 JS 读回标题、简介的实际文本,和文案文件逐字对照。
6. 列一张「已填 / 没动的默认项」表给作者,然后**停手**。
7. **视频号这类微前端页面**(wujie:`<wujie-app>` 的 shadow DOM 放界面,脚本跑在一个名为 `content` 的 iframe 里):
   - 扩展的 find / read_page 看不到表单,输入框只能按截图坐标点;**每次点击前重新截图**,填完用 JS 进 `shadowRoot` 读回。
   - 文件上传:扩展只能往它看得见的 input 里传。先在主文档放一个临时 `<input type=file>` 接住文件,再用 JS 转交给 shadow DOM 里真正的上传框。
   - **转交时 File 和 DataTransfer 要用那个 iframe 的构造函数新建**(`iframe.contentWindow.File`),再派发 `change`。直接把主页面的 File 塞进去,页面不报错也不接收(本次第一次就是这样静默失败的)。
   - 转交完删掉临时 input。

### 2026-10-01 补丁:横版母版四平台(B站 / 抖音 / 快手 / 小红书)

来源:71_余温《瑟兰薇》角色 PV,16:9 横版,同一天依次投稿。分工照旧:作者扫码登录、手动选视频文件、确认后点发布,助手填其余字段。

**横版母版要准备的封面**(和竖版那次不一样的地方加粗):

| | B站 | 抖音 | 快手 | 小红书 |
|---|---|---|---|---|
| 封面 | 16:9 + 4:3 两格,**在封面弹窗里先选中那一格再传,两格各传各的**(不要让 B站从一张自动裁) | 横 4:3 + 竖 3:4 两格 | 一张 3:4 | **横屏视频的封面框是 4:3**;传 3:4 会被裁(这次切掉了标题字)。**一次只能留一张自定义封面**,换图先点缩略图上的 × |

**小红书字段(首次,2026-10-01)**:

- 标题 ≤20 字;正文一个框,话题写在正文里,输 `#词` 等联想、点第一条才是正式话题。
- 内容类型声明 →「笔记含AI合成内容」。
- 原创声明开关:打开时会弹《原创声明须知》,**勾选同意要作者本人点**。
- 合集、群聊、话题,作者可能在页面上自己加。发布前把所有字段读一遍,多出来的先问是不是作者加的(这次是,保留)。

**新踩到的坑与做法**:

- **B站**:
  - 新分区只有一级,选「影视」,没有「短片」子区。
  - 「创作声明」下拉里有两项:「含AI生成内容」「内容为自制,禁止转载」,可以都选。
  - 页面上还有活动话题和流量奖励(这次用了 1000 曝光),都要作者决定;用了流量奖励,首小时数据就要扣掉这部分曝光再看。
  - 下拉展开有动画,选项叠在下层元素上。等 1–2 秒、截图拿稳坐标再点,按旧坐标盲点会选错。
  - 标签每回车一个,等 1 秒、重新点一次输入框再输下一个。连续输入只成功了 1 个。
  - **置顶评论**:评论区在 shadow DOM 里,扩展的 find 看不到。用 JS 逐层穿透 `shadowRoot` 找到自己那条评论的 `#more`(三个点),点开菜单选「设为置顶」。
  - 发布时间从公开接口读 `pubdate`,不要凭印象写"约几点"。
- **抖音**:标题栏 ≤30 字和简介分开填,话题写在简介里;横版视频横、竖两张封面都要传。
- **快手**:
  - **活动卡上的「添加」不起作用**,只弹出「请手动添加相关话题」。参与活动,要在描述里输入活动话题(这次是 `#AI灵境计划`),在联想里点选,变成正式话题标签才算。能不能计入活动,要去 App 里确认。
  - 选下拉选项时,点击可能穿透到下面的「加入合集」,这次被误选成一个已有合集。发布前把所有字段读一遍。
- **横版片在竖屏平台**:抖音、快手、小红书都按横屏播放,上下留黑。这次没有另出 9:16 竖版。

### 2026-10-14 补丁:六平台(B站 / 抖音 / 即梦 / 快手 / 小红书 / 视频号)

来源:84_那道题还亮着 原创男女对唱 MV(16:9 / 3 分 17 秒),10-13 到 10-14 依次投稿;同时回头修了 71_余温先导片被小红书限流的那条笔记。

**最大的一条:小红书不能出现任何其他平台的信息。**

- 余温先导片 10-11 在小红书被判「未通过」:**「笔记存在推广其他平台的内容」**,处置是限制推荐和搜索展示,所以几乎没有曝光。正文里写了「画面与声音:即梦 Seedance 2.5 · 角色与场景:Midjourney」「配乐:Suno 原创」,还带了话题 #即梦AI。
- 规避:视频用「无竞品版」(片尾署名只写 AI);标题、正文、话题都不写 Suno、即梦、Seedance、Midjourney、B站、抖音之类的名字;正文下面的推荐话题会冒出 #midjourney,别点。
- 补救:笔记管理 →「查看修改建议」→「修改笔记」,删掉平台名后提交,会重新进审核。正文是 ProseMirror 编辑器:用 JS 把选区精确设在要删的段落、文字或话题标签上,再按真实 Backspace,不要直接改 DOM。
- 作者的社群话题 #野神殿 **只在小红书**默认加;视频号、抖音、快手都不加。
- 活动在页面「关联活动 → 更多」里挑(四十来个,大多与题材无关);这次关联了「小红书校园音乐季」。

**话题上限**:抖音最多 5 个正式话题,第 6 个只会是纯文字;快手最多 4 个。

**抖音**:
- 重新上传视频后,横、竖两张封面都会被清空,要重传。
- 删正文里的残留文字别直接按 Backspace,光标位置不可靠,会删掉整颗话题;先用 JS 选中要删的文字再删。
- 抖音号、UID、播放 / 点赞数从创作者中心的 `work_list` 接口读(`author.unique_id`、`author.uid`、`statistics`),不用去 App 里点版本号。

**快手**:作品 ID(用于 `kuaishou.com/short-video/<id>`)在视频管理页卡片组件的 `__vue__.$props.workId` 里。

**即梦**:要参加锋芒回响的画布激励,短片必须从画布入口发,见 [[即梦锋芒回响_画布绑定发布与开源画布整理_v1]]。

**视频号(第二次)**:
- **短标题不能有逗号**,只允许书名号、引号、冒号、加号、问号、百分号、摄氏度;逗号用空格代替。
- 封面现在分两格:「个人主页卡片 3:4」和「分享卡片 4:3」,各自点「编辑 → 上传封面」。
- 话题要一个一个打:`#词` 后按一次空格,等它变蓝再打下一个;一口气连打 `#a #b ` 会变纯文字。
- 活动下拉要搜关键词,搜出来的绝大多数是个人号自己建的「活动」;官方的名字以「微信时刻 ·」开头。
- **封面代理上传这次失败了**:只把 `Event` 换成了 iframe 的,`DataTransfer` 用的还是主页面的,组件不接收,最后由作者手传。上面「填表时的做法」第 7 条早就写着要用 `iframe.contentWindow` 的 `File` 和 `DataTransfer`。**动手前先查本文**,别重新试错。
