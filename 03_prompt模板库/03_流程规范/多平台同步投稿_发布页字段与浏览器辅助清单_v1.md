# 多平台同步投稿:发布页字段与浏览器辅助清单

> 入档:2026-09-26
> 来源:76_清月 发布(9:16 / 15 秒 AI 短片),B站 → 抖音 → 快手依次投稿;助手用 Claude in Chrome 填表,作者上传视频、登录、点发布
> 验证状态:⚠️首次(三个平台各一次;平台改版后字段位置可能变)

## 一句话

同一条竖版母版发三个平台,**要准备的封面比例不一样**:B站要 4:3 和 16:9 两张,抖音要竖 3:4 和横 4:3 两张,快手一张 3:4。每个平台的 AI 声明在不同位置,叫法也不同。助手能填的都填好,**停在发布按钮前**,由作者审完自己点。

## 如何使用

### 开工前准备(一次做完,三个平台共用)

- 成片母版(原版,不压缩)。
- 封面三张:**3:4 竖版**、**16:9 横版**、**4:3 横版**。4:3 从 16:9 本地无损裁出即可,不用另外出图。
- 每个平台一段文案(标题 / 简介 / 话题),事先写进一个文件,便于核对。

### 分工

| 作者 | 助手 |
|---|---|
| 登录(扫码)、上传视频文件、点「发布 / 投稿」 | 填标题、简介、话题 / 标签,传封面,选分区,勾 AI 声明,最后列出已填内容和没动的默认项 |

- 视频由作者传,理由不只是体积上限,见 [[浏览器插件自动化的能力边界_v1]] 的 2026-09-26 补丁:**不要为了能自动上传而压缩母版**。
- 作者传完视频,把那个标签页拖进 Claude 的标签组,助手再接手。

### 三个平台的字段(2026-09-26 实测)

| | B站 | 抖音 | 快手 |
|---|---|---|---|
| 标题 | 独立标题栏,≤80 字 | 独立标题栏,≤30 字 | **没有标题栏**,标题和描述合写进「作品描述」 |
| 简介 / 描述 | 独立简介框 | 独立简介框,话题也在这里 | 「作品描述」一个框 |
| 话题 / 标签 | 标签单独一栏,回车成签;**会自动预填无关标签**(这次是「直播、生活记录、记录」),要删掉 | 输 `#` 后从候选里点选,变蓝才是正式话题 | 同抖音;候选里没有的可以手打 |
| 封面 | **4:3「首页推荐」+ 16:9「个人空间」两格**;另有可选的 PK 封面(A/B 测试用) | **竖封面 3:4 + 横封面 4:3 两个页签**;有封面检测 | 一张,从上传页签传 3:4 原图 |
| AI 声明 | 「创作声明」下拉 → **含AI生成内容** | 「自主声明」→ **内容由AI生成** | 「作者声明」→ **内容为AI生成** |
| 分区 | 要手动改;这次被自动选成「影视」,改成「动画」 | — | — |
| 默认开着、要作者决定的 | 定时发布、合集、商业推广、转载授权 | **「同时发布到」今日头条 / 番茄小说**(账号记住的设置) | 允许跟拍同框、允许下载、同城页展示 |
| 陷阱 | 标签输入框回车后会失焦,每个标签前重新点一次 | **话题候选旁边就是官方活动卡片**,点偏会把活动插进简介(这次误加了一个,已删) | 候选里的近似话题(「#国风仙」「#aigc」)不是要的那个,别顺手选 |

### 填表时的做法

1. 每个平台开始前先截一张全页图,看清各个上传位分别对应什么比例。
2. 页面里常有好几个隐藏的文件框。先用 JS 给每个 `<input type=file>` 标上名字再定位,传完切回另一个页签确认没传错位置。
3. 富文本框别用 `Ctrl+A`,会选中整页;点进框里再清空。
4. 选话题和候选项用元素定位,不要靠坐标点(抖音那次误点就是坐标偏了)。
5. 填完用 JS 读回标题、简介的实际文本,和文案文件逐字对照。
6. 列一张「已填 / 没动的默认项」表给作者,然后**停手**。

### 发布后

- 各平台链接和首小时数据回填到项目的发布文案文件。
- 投流判断按 [[快手分发SOP_v1]] 的规则:自然流量没跑出来不投流。

## 边界

- 视频号、小红书这次没发,字段未知。
- 平台改版后字段的名字和位置会变,表格只代表 2026-09-26 那天的页面。
- 全程在作者已登录的 Chrome 里操作。登录、验证码、发布都没有由助手代做。
