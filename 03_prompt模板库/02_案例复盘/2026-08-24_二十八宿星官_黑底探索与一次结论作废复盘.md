# 2026-08-24 · 二十八宿星官 · 黑底探索与一次结论作废复盘

> 性质：**探索型复盘**，非比赛、非交付、无平台数据。作品线仍在建设中。
> 题材：二十八宿星官（西方白虎七宿）——参水猿 Shen Shui Yuan / 昴日鸡 Mao Ri Ji
> 工具：Midjourney v8.2
> ⚠️ 本篇含 **AI 助手侧连续误判全记录**，见第四节。

---

## 一句话

**同一条骨架，把「纯白背景 + 矿物平涂」换成「纯黑背景 + 辉光」，题材立刻成立。**

另一半更该记：本次还产出过一条「moodboard 跨族覆写明确指令」的结论并推进了知识库，**当晚因核对出证据无效而整条作废**。作废经过写在第五节，误判记录在第四节第 6 行。

---

## 事实时间线

1. 作者拿来一条参水猿 prompt（白底工笔平涂 + 巨型天猿）要求优化。助手按字面的 `pure white background` 给出「大留白工笔平涂」全案：压 `--stylize`、挂 `--style raw`、把手藏进袖子、`--no` 挂十余项。
2. 作者补充想拿一张冷紫暗调插画当 sref，反馈"人脸不够好看"。助手诊断 sref 传不了脸（**成立**，产出 [[参考图缺失维度不可继承律_v1]]），但把该 sref 与"白底工笔"判为跨族冲突（**前提本身是错的**）。
3. 作者出示朋友的昴日鸡成品图与 prompt：**同一骨架、纯黑背景、无 `--no` 参数、无 personalize、无 moodboard**，一版即成立。作者判断"我们走偏了"——**成立**。
4. 作者补跑一版加 personalize + 既有「美女写真」moodboard，出图是当代清冷少女写真。助手据此立律并入库。
5. 当晚作者贴出该版实际使用的 prompt——**是同轮的近景调脸 prompt，不是星官 prompt**。逐项核对后该批出图零失守，第 4 步立的律整条作废，五处档案回滚降级。

---

## 三条实测结论

### 1 · 黑底是这个题材的总开关 ✅

白底 + 矿物平涂 + `soft divine glow` 是**三个互相打架的诉求**：辉光在白底上必糊，平涂拒绝渐变，而"神性"恰恰要靠辉光。换成黑底，三者同时和解——辉光自动获得对比度，背景不确定性归零（比任何 `--no busy background` 都强），冷色系有地方沉下去。

⚠️ **连锁纠正**：[[MJ_v8.2_行为档案_v1]] 的「克制 / 冷调 / 大留白项目要反压 `--stylize`」是按**画面取向**判的，不是按背景颜色判的。黑底 + 强辉光落在 v8.2 的**顺风区**（bold / 强对比），默认 `--stylize 100`、不加 `--style raw` 才对。助手把"白底"误当成"克制"，压 stylize 的建议方向反了。

### 2 · 伴生神兽要选「没有肢体语义的填充母题」✅

鸡的尾羽是纯装饰曲线，铺满画面左三分之二也不会被读成多长了什么。猿有四肢，同一个句式（`... and flowing robes forming layered ... shapes`）主语从「羽毛」换回「长臂」，`extra arms` 风险立刻回来。

**迁移到系列**：每一宿都要先找到它的**非肢体填充母题**。参水猿 → 水（对位星官名的"水"，曲线自由度等同羽毛、零肢体语义）；觜火猴 → 火。两只灵长要靠体型与动势拉开（猿高大安静垂臂 / 猴矮小灵动），不能只靠色温分。

### 3 · 自然语言 `no` 挡得住物种，挡不住颜色 ✅

朋友那版 prompt 末尾是自然语言 `no phoenix, no red, no orange, no warm colors, ...`（**不是 `--no` 参数**）。同一张图里：

- `no phoenix` **命中** —— 出的是鸡不是凤，尽管尾羽极凤
- `no red, no orange, no warm colors` **失守** —— 唇是明确的橙红

**而这次失守是资产**：那点橙红是全图唯一暖色，正落在视觉焦点上，撑起整张冷调图的体温。若改用 `--no red, orange` 参数硬压，画面会变平。这是 [[默认落点的资产负债判断_v1]] 的又一个样本，且首次落在**颜色**维度（原档样本是年代原型）。

## 助手侧误判全记录 ⚠️

| # | 误判 | 根因 | 纠正 |
|---|---|---|---|
| 1 | 按 `pure white background` 优化，给出大留白工笔平涂全案 | **对着字面走，没有回问"你要的是白底还是发光"**。看出了白底与辉光自相矛盾，却选择迁就错的那一半（把辉光改写成线条） | 需求里自相矛盾的地方要暴露给作者定夺，不是替他选一半 |
| 2 | 建议压 `--stylize` + 挂 `--style raw` | 由误判 1 连锁——把"白底"读成"克制大留白" | 判断依据错了结论跟着错。**依据变了要整条重判，不是微调** |
| 3 | 建议把手藏进袖子、撤掉手部正向词 | 「正反夹击导致手崩」这条规律的前提是**同时用 `--no` 参数**做负权重。朋友那版全是自然语言 no，不构成夹击 | 规律要连前提一起迁移，不能只搬结论 |
| 4 | 建议 personalize 强制开 | 那条结论的场景是**当代清冷少女**（personalize 的作用是把脸从复古原型拉回当代）。古典星官题材要的正是复古原型 | 见 [[AI甜妹脸vs复古东方美人]] 2026-08-24 补丁 |
| 5 | 把冷紫 sref 判为与本题材跨族 | 前提（白底工笔）本身错。方向改成黑底冷紫后，该 sref **完全同族**，可直接挂 | 前提错时，基于它的所有推论要整批重跑，不是逐条打补丁 |
| 6 | **把一个未确认变量下的推论写成实测证据，并推进知识库** | 已经识别出「未确认跑的是哪条 prompt」这个变量，却只把它写成文末的边界声明，正文照旧按「星官 prompt 被覆写」陈述并据此立律 | **未控变量不是脚注，是拦路石**。变量没定死之前不立律——[[新模型试跑_硬锁清单先行_v1]] 的「入库前逐条过硬锁」同样适用于结论入库 |

**第 1–5 条的共同根因**：把作者写的 `pure white background` 当成了确定需求，而它其实是作者**还没想清楚的部分**。

**第 6 条是另一条，而且更该记**：识别出了未控变量，却没有让它拦住结论。**一份带着「⚠️ 未验证」标签的错误结论，仍然是错误结论**——标签只是免责，不是校验。正确顺序是**先问一句把变量定死，再写**。本次那一问只差一句话的成本，却让五处档案要回滚。

**可迁移的自检**：拿到一条待优化 prompt，先扫一遍**内部矛盾**（这里是"纯白底"×"发光"×"平涂"三选二），矛盾处一律回问，不要替作者选。这一步在 [[已有prompt的七步体检律_v1]] 的第一步「查冲突」里已有，本次是没执行，不是没有。

## personalize + moodboard 那一版：一次作废的「发现」 ⚠️

作者补跑了一版加 personalize + 既有「美女写真」moodboard 的图，出图与星官题材毫无关系：当代少女、短 bob、露肩、高调白底、珍珠链 + 白毛领 + 四芒星光。

**当时的判断**：moodboard 跨族争夺主体，把 prompt 写死的 `pure black background` / `long black hair` / `exquisite flowing Hanfu` / 神兽全部覆写；珍珠链、白毛领、星芒是 moodboard 的伴生元素沿模糊槽灌注进来的。据此立了一条律并推进知识库。

**当晚核对作者实际使用的 prompt 后，以上全部作废**——那一版跑的**不是星官 prompt**，而是同轮的一条近景清冷少女 prompt（助手自己上一轮给的调脸 prompt）。逐项对照：

| 当时断言「被覆写」 | 核对结果 |
|---|---|
| `pure black background` → 高调白 | prompt 里没有黑底。正文写的是 `her whole face fully lit and clearly readable not lost in shadow`——**高调是 prompt 自己要的** |
| `long black hair` → 短 bob | prompt **没写头发**，属修正三记载的正常「模糊槽填空」 |
| `exquisite flowing Hanfu` → 露肩现代装 | prompt **没写汉服**，写的是 `white fur collar`，且命中 |
| `large sacred celestial rooster` → 消失 | prompt **没有神兽** |
| `gongbi / mineral pigment` → 柔焦写实 | prompt 写的是 `cinematic digital painting` + `soft airbrush shading`，命中 |
| 珍珠链 / 白毛领 / 星芒＝moodboard 伴生渗透 | **三样都写在 prompt 正文里**，属正常执行 |

那一版还**没挂 `--sref`**。逐项核对下来，该批出图**几乎全中、零失守**。

**这一版真正证明了什么**（把它当同族样本重读）：

- 当代少女 prompt × 当代美女写真 moodboard × personalize 开 × **无 sref** ＝ 一个干净的**人物题 ＋ 同族**样本，全项命中，脸质量明显优于此前挂无脸 sref 的几批。
- 印证 [[personalize与moodboard分工]] 修正二（同族 → 精准贡献主体维度）。
- 印证 [[参考图缺失维度不可继承律_v1]] 的操作建议：**脸不走 sref，走描述锚定 ＋ personalize**——撤掉 sref 反而把脸修好了。

**作废后的处置**：原《moodboard 主体争夺律 v1》降级改名为 [[moodboard主体位判据_假说_v1]] 🔬，覆写表与灌注路径段删除，「人物题 ＋ 跨族」一格标为零样本；[[AI甜妹脸vs复古东方美人]] 与 [[personalize与moodboard分工]] 的对应段落同步降级为待验证推论。

## 系列层建议（待作者确认是否成系列）

参水猿与昴日鸡同属**西方白虎七宿**。若做整个二十八宿：

- 骨架就是现在这条。[[骨架篇幅即权重_v1]] 与 [[MJ_v8.2_行为档案_v1]] 第 7 条实测过：**103 词共用骨架 + 各换一句变量从句，四张零重跑，不挂 sref 也锁得住**；骨架里某成分写得越细，其跨图稳定度越高。
- 固化三段：人物段（最长、写最细）、黑底 + 冷调辉光段、风格段。
- 每宿只换四项：星官名 / 神兽 + 形态从句 / 该兽的 `no xxx` 排除项 / **非肢体填充母题**。
- 填充母题提前排布避免撞形：奎木狼→毛流与霜，娄金狗→金属云纹，胃土雉→雉羽（与鸡撞，需错开），昴日鸡→尾羽 ✅，毕月乌→墨羽与月轮，觜火猴→火，参水猿→水 ✅。
