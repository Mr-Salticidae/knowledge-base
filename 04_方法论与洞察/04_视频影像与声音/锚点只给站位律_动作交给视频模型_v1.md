# 锚点只给站位律：动作交给视频模型 v1

**一句话**：给 Seedance 的静态参考只定"谁在哪、朝哪、门开没开、冠在不在"，人物一律自然站姿；动作、手势、景别、切换写在提示词里，由模型演。把动作画死在图上，模型只能往那个姿势上硬靠，反而假。

验证等级：⚠️ 首次发现（《余温》M02 试镜 r1→r2，2026-09-20；作者目视判断，单项目一次对照）

## 现象长什么样

同一段 25 秒（王走到门前被守门人拦下、摘冠、门开、跨门），两条只差两张锚点：

| | 锚点 2、3 | 作者判断 |
|---|---|---|
| r1 | 守门人横臂拦在王胸前、掌心抵胸甲（摆好的动作） | "布兰拦门前后太假" |
| r2 | 两人自然相对而立，双臂垂下 | "好多了" |

r2 里守门人在 3 秒自然相对之后**自己**抬臂横到王胸前——同样的手势，但它是从站姿里长出来的，前后接得上。r1 的锚点把手势钉在了一个时刻，模型为了"到达"那张图，前后的过渡都在硬凑。

同一个方向上作者前一天已经否过一次：85 镜 111 张逐镜首尾帧——"颗粒度太细了，只需要几个关键帧，给 Seedance 2.5 创作空间"。

## 为什么

视频模型擅长的正是"两个状态之间怎么演"；逐帧或逐姿势的锚点是把它当插值器用，既压死了表演，也在每个锚点处制造一次"必须对上这张图"的硬约束。官方对 Seedance 2.5 白模参考的描述是同一件事：模型从白模里取"运镜、节奏、景别变化、主体轨迹、站位"，材质、光照、人物自己渲——取的是空间与时间结构，不是姿势。

## 操作规则

1. 每段 4–6 张锚点，每张对应一次**状态变化**（冠在不在、门开没开、甲在谁手里、影子还有没有），不出动作中间帧。
2. 锚点里不画横臂、抵胸、抬手等具体动作；人物自然站姿或行走。
3. 锚点必须是成立的画面：人物完整在画里，不做"只露一截手臂、人却不在画里"的近景。
4. 动作顺序写在提示词的时间表里，只写每段发生什么，不逐镜规定景别与机位。
5. 姿势规则（如"空袖对折搭在横在腰前的左小臂上"）用文字写，实测模型能照做，不必为它出标准图。

## 反例 / 边界

- 匹配剪（同构图冷暖切、爱人消失只剩空袖）仍需逐像素派生的两张图——那是"两个状态"，不是"一个动作"。
