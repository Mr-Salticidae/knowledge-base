# 派生图不进视频输入律：噪点随编辑代数累积

**一句话**：GPT Image 每多派生一代，噪点就叠一层；把这样的图挂进 Seedance 全能参考，视频会把噪点当质感学走。人物身份只用 MJ 原图或一代定妆图，姿势规则写进文字，不靠改图。

验证等级：⚠️ 首次发现（《余温》M02 试镜 r2→r3→r4，2026-09-20；作者目视判断，单项目一次逐变量对照）

## 现象长什么样

M02 的站位锚点与身份图走的是一条 GPT Image 派生链：K09 v3 → v4 → KF11 v3 → 站位 v4 → 站位 v3，四五代。作者看 r2："画面很脏……用 GPT 改图就会出现越改噪点越多的问题。"

之后每条只换一样东西、提示词逐字不变：

| 轮 | 换了什么 | 作者判断 |
|---|---|---|
| r3 | 五张锚点换成 r2 视频自己的抽帧 | （脏没变） |
| r4 | 身份图换成 MJ 原图（A01/A11/A12）＋真人一代定妆＋道具单体图 | "不脏了，只是分辨率低" |

→ 脏来自身份图这一路的 GPT 派生，不来自锚点。多轮编辑的误差累积在文献（EdiVal-Agent 等）和 OpenAI 社区都有记录，经验法则是超过两轮就开始变差；这次是它第一次在视频端被看见。

## 助手的指标为什么没量到

助手用"平坦区 3×3 高通残差标准差"比 r2/r3/r4，数值相当（0.52–0.92），据此写"r4 没有更干净"。作者一眼看出 r4 干净。作者看到的更可能是色斑、块状纹理、塑料感一类**低频**的脏，不是高频颗粒。这条律以目视为准，指标弃用。

## 操作规则

1. 视频输入里的人物身份图只用 MJ 原图，或真人照片经一次 Image 2 的定妆图；GPT/Codex 派生图一张都不进。
2. 站位锚点用 Seedance 自己的输出抽帧或 Blender 白模，不用 GPT 改图。
3. 静帧非改不可（去冠、换道具）用即梦 Seedream 5.0 Pro，只从原图派生一代，不链式改。
4. 姿势规则（搭袖、抱冠）写进提示词；实测只靠文字模型就能照做。
5. 总则里不要写"派生优先"——同机位一致性用白模或抽帧保证。

## 反例 / 边界

- MJ 原图自带的造型问题会原样进片（本案 A01 的外扩尖角护肩），要改只能在 MJ 侧重出。
- 分辨率是另一件事：720p 出片、后期超分即可，不要为"看清楚"跑 1080p 试镜（20 分/秒 vs 65–70 分/秒）。
- GPT 派生图不是不能用，是不进**视频输入**；封面、示意图、审看画布仍可用。
