# 跨镜道具锁定律：资产图优于形容词 v1

**一句话**：一件道具只要出现在两个以上镜头，就得有一张属于它自己的参考图。提示词里写多少形容词，模型每一镜都会重新想象一次。

验证等级：⭐⭐ 二次验证（《余温》宣发片 2026-09-18；《余温》M03 银枝头冠 2026-09-16）

## 现象长什么样

一封"带一枚暗红火漆蜡封的对折羊皮纸信"，提示词里写清楚了，25 秒片子里跨四个镜头：

| 镜头 | 信的状态 | 蜡封 |
|---|---|---|
| 甩出、落在桌上 | 对折 | 看不清 |
| 平放在桌上 | 平摊 | **没有** |
| 被拿起来看 | 举起 | **没有** |
| 最后的锁死插镜 | 平摊 | **出现在纸的左侧** |

作者的原话是"红漆不应该移动位置"。**但它不是在移动，是这封信在每一镜里都是新造的一件东西**——有的那次带蜡封，没有的那几次就不带。

同一个病在这个项目里犯过第二次：一顶"纤细不对称的旧银枝额冠"，光靠文字描述，被生成成了等距尖齿的厚圆箍。两次都是补了独立道具图才治住。

## 为什么形容词治不了

全能参考这类接口里，**参考图是硬约束，文字是软约束**（见 [[Seedance2_5_行为规律_v1]] 第四节：参考图里有的东西，prompt 与负面词都压不住）。道具没有自己的参考图时，它只存在于文字里，于是每个镜头各自解释一次"暗红蜡封"，解释出"这一镜不需要它"也完全合理。

## 怎么做

1. **开拍前列一张跨镜道具清单**：出现在两个以上镜头的道具，逐个确认有没有资产图。没有就先补图再开拍——补拍一段的成本远高于出一张图。
2. **资产图要成套，覆盖状态变化**：同一件道具的对折／展开、完整／破损、空／满，各给一张。只给一张展开图，模型照样会自己编对折的样子。
3. **成套的图先互相比色再用**。本次第一批出了两张，蜡封一暗一艳（红色像素差 14%，RGB 均值差一档）。这种差在静图上看不出来，进视频会被放大成"这两镜不是同一件东西"。量一下比看一眼可靠：

   ```python
   # 两张资产图里同一件道具的颜色/面积是否一致
   a = np.asarray(Image.open(f).convert('RGB')).astype(float)
   r, g, b = a[..., 0], a[..., 1], a[..., 2]
   m = (r > 70) & (r - g > 55) & (r - b > 45)       # 按道具主色调改阈值
   print(m.sum(), [round(a[m][:, i].mean()) for i in range(3)])
   ```

4. **提示词写"可见性"，不写"一致性"**。把"保持一致"换成一句可判定的话：

   ```text
   这件道具全段是同一件：对折状态以 @Image5 为准，展开状态以 @Image6 为准。
   任何一个能看见它的镜头里，都必须看得见那枚暗红蜡封；它不消失、不移动到别处、
   不变大、不变色、不被手挡住超过半秒。
   ```

5. **验收也要跨镜量**，不要只对比首尾两帧。本次差点因为只量了首尾帧（位移 1.7 像素）就判"没问题"；把道具在每个镜头里的状态列成表才看出中间三镜根本没有它。

## 效果

补上「对折封蜡」「展开带文字」两张资产图、只重拍出问题的那 14 秒之后：蜡封在飞行、落盘、锁死插镜三处都在，而且始终在纸的同一侧。作者一次通过。

## 举一反三

同一条律适用于：角色的随身物（吊坠、耳饰、护腕）、伤痕与妆效、可拆卸的服装部件、被传递的信物。判据都一样——**观众能在两个镜头里同时想起它，它就需要一张图**。

## 边界

- 只在单镜出现的道具不值得为它出资产图。
- 资产图本身不一致时，这条律会反过来放大问题（见步骤 3）。
- 资产图锁的是"长什么样"，锁不住"在谁手里、朝哪个方向"——那要靠相邻帧锁站位，见 [[按切点重拍_省的是生成时长_v1]]。
