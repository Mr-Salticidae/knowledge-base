# 氛围曲的结构在音色，不在响度 v1

> 来源：65_过风 项目 2026-08-26 · Suno 无词哼鸣配乐接入剪辑
> 性质：**方法适用边界**——不是原方法错，是它有前提，而我没检查前提就换了素材

## 一句话

**无词哼鸣 / ambient 这类持续音乐没有响度乐段，RMS 包络找不到结构点，
必须用频谱流量（spectral flux）测音色变化。**

## 触发案例

剪辑口径是 [[2026-08-24_擦干净_从素材到动态化制片_全链路复盘_v1]] 的
**音频先行 ⭐⭐**：不改音乐，改画面对位——把音乐最清楚的结构点挪到镜头切换处。

为此写了个工具按 **RMS 包络**找「最大下降沿」。对**第一版配乐**（有明显乐段落差）管用：
它有一道 −6.2 dB 的台阶，一次就定位到。

换到**定版的无词哼鸣曲**上直接失灵：

```
全曲跨度 36.0 dB   ← 看起来「落差很大」
body 跨度 17.0 dB  ← 掐掉首尾淡入淡出后的真相：连续波动，没有任何台阶
```

改用频谱流量后，同一条曲子一次找出 19 处 z>1.2 的乐段边界，
工具独立复现了手算选点（72.28s vs 手算 72.30s）。

## 落地

1. **先算 body 跨度**（掐掉首尾各 4s 的淡入淡出再算）：
   - `> 25 dB` → 有响度乐段，RMS 够用
   - `≤ 25 dB` → **必须上频谱流量**
2. **不能拿全曲跨度做判据**——淡入的 −47 dB 会把跨度撑大，把氛围曲误报成「有落差」。
   本曲全曲 36 dB、body 仅 17 dB，就是这个陷阱。
3. 频谱流量的算法：逐帧幅度谱取 log → 正向差分 → 逐帧能量 → 按 0.5s 聚合 → 转 z 分数，
   峰值 z>1.2 即候选边界。
4. **z 是相对所分析片段的均值/标准差算的**——换片段就换基准。
   对 28s 成片复核时数值会与全曲分析时不同，属正常，不是对位失败。

## 反例 / 边界

- 有鼓点、有节拍网格的素材：用 onset 检测更直接，本条不适用。
- 频谱流量对**混响尾巴**和**渐变音色**不敏感——如果一首曲子的乐段是靠和声色彩缓慢推移区分的，
  两种方法都找不到硬边界，那时只能人耳打点（见 [[人耳打点吸附_卡点裁决权归人耳_v1]]）。
