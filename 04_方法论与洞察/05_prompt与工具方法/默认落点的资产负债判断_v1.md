# 默认落点的资产负债判断 · v1

> 入档：2026-08-20
> 触发：《雨里旧信》1940s 老上海爵士封面，第一版把 `pin-up / calendar girl` 写进 `--no`，结果关掉了唯一能免费给年代感的机制
> 性质：给 [[获奖图复盘方法论合集_活合集]] 第 40 条「负面词的预防式接种」⭐⭐ 划**边界**
> 验证状态：⚠️ **首次发现**，单案例、非比赛、无平台数据

---

## 一句话

**「预判默认落点并接种」的前提，是先判断这个默认落点对你是资产还是负债。** 看见"模型可能跑偏的方向"就无差别塞进 `--no`，有时候压掉的正是你唯一免费能拿到的东西。

---

## 它给哪条规律划边界

第 40 条「负面词的预防式接种」教的是：**赛前预判画面最可能的翻车方向，第一版就接种**，其中第四个高发方向是「风格词的默认落点漂移」——写宽泛风格词，模型会滑向该词最主流的那支子方言，要哪支就把其他方言写进 `--no`。

这条规律没错。**它缺的是前置的一步分类**：

```text
第 40 条：预判默认落点 → 接种
本条补：预判默认落点 → 【先分类：资产 or 负债】→ 只对负债接种
```

---

## 案例（本条的来源）

题材：1940s 老上海爵士唱片封面，需要一位东方女性主体。

**我做的**：预判 MJ 拿到「1940s 上海 + 旗袍 + 女人」会滑向"月份牌美人 / 交际花"，于是第一版 `--no` 里写了：

```text
pin-up, advertisement poster, calendar girl, smiling,
sequins, feathers, heavy makeup, stage, nightclub
```

理由听起来成立：月份牌美人甜、艳、正面朝镜头笑，与角色设定的"安静的住户"相反。

**实际上**：[[AI甜妹脸vs复古东方美人]] 记录了一条双盲实验级结论——

> MJ base model 默认输出的不是"中国脸"，是西方训练集对东方面孔的**复古化想象**——民国老照片质感的东方美人。
> 文化原型：**老月份牌女郎** / 好莱坞经典电影里的中国小姐 / 1930s-1950s 时尚摄影里的"东方美人"。

**"老月份牌女郎"这个默认落点，正是 1940s 老上海。**

该档同时记录了反向增量：同一个机制，换个场景就从陷阱变成可用资产，判断口诀是「要当代甜妹就开 personalize 并避开这套词；**要复古胶片就大胆堆**」。

**结果**：那一版 `--no` 把唯一能免费给年代感的机制自己关掉了，同批还因为漏写族裔跑出白人脸。改为**主动调用**复古东方美人五官词块、并用气质层把"甜艳"扭成"疏离忧郁"后，一轮修好。

---

## 操作规则

1. **写 `--no` 前，对每个词问一句**："这个方向在**本题材**里，我到底要不要？"
2. **同一个默认落点在 A 题材是陷阱、在 B 题材是资产**——判断看题材，不看词本身。
3. **警惕跨项目复制的 `--no` 清单**。上一个项目的负债，可能是这个项目的资产。
4. 判定为**资产**时，不只是"不压制"，而是**主动调用**（把它写进正文的词块里），并用其他槽位（如气质层）微调它的取向。
5. 判定为**负债**时，再按第 40 条接种。

### 分类速查

| 问 | 判定 |
|---|---|
| 这个默认落点的年代 / 地域 / 媒介，和我的题材对得上吗？ | 对得上 → 大概率是资产 |
| 我要压的其实是它的**取向**（太甜 / 太艳 / 太亮），不是它的**身份**？ | 是 → 资产，用其他槽位调取向，别整个压掉 |
| 它和题材的核心设定直接冲突？ | 是 → 负债，接种 |

**第二问是关键**：很多时候你反感的只是默认落点的某一个维度，而不是它本身。整词压掉是把孩子和洗澡水一起倒了。

## 反例 / 边界

- **本条不是"少用 `--no`"**。该压的还得压——[[AI甜妹脸vs复古东方美人]] 在当代小红书甜妹题材里，这套复古东方美人就是要避的陷阱。
- 与 [[负面词计入prompt浓度_v1]] 是两回事：那条讲 `--no` 的**成本**（token 浓度），本条讲 `--no` 的**方向**（压错了对象）。两条可以同时踩。
- ⚠️ 单案例、非比赛、无平台数据验证。**只能作为待观察假设，不能用于指导下一次决策**，需再验一次方可升格。

## 第二个样本：颜色维度（2026-08-24）⚠️

来源：[[2026-08-24_二十八宿星官_黑底探索与一次结论作废复盘]]。

一条星官 prompt 末尾写了自然语言 `no red, no orange, no warm colors`，出图里唇仍是明确的橙红——**压制失败**。

但那点橙红是**全图唯一的暖色**，正落在视觉焦点上，撑起了整张冷调图的体温。若改用 `--no red, orange` 参数硬压成功，画面反而会变平。

**增量**：本档原样本（月份牌女郎）是**年代原型**维度，这次是**颜色**维度，说明"预判到就本能压制"的失误形状**不挑维度**。同时给出一个新的自检角度——**压制失败时先别急着换更硬的手段，先回头问一句它是不是资产**。

⚠️ 同为单案例、无对照。两个样本方向一致，本档验证状态由「⚠️ 首次发现」升为 **⭐⭐ 二次验证（跨维度）**。

**同批的工具侧结论**：自然语言 `no` 挡得住物种、挡不住颜色（同图对照：`no phoenix` ✅ / `no red` ❌），见 [[MJ_v8.2_行为档案_v1]] 第 9 条。
