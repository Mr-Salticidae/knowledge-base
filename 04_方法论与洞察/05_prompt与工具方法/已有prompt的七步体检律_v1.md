# 已有 prompt 的七步体检律 · v1

> 入档:2026-08-18
> 触发:《目标是成为 Prompt 大师》第 13 期《月白》——素材是一条 130 词的「网上流传款」古风人像 prompt,逐条改完再跑
> **性质:综合档,不含新证据。** 七步全部由已验证的原子档组成,本档只做**执行次序**的编排

---

## 一句话

**库里所有 prompt 方法论都在教"怎么写",但大多数人的真实处境是"手上已经有一条,跑不对,不知道该动哪个词"。** 这七步是把既有规律排成一条可以照着走的体检次序——**先减后加,先删冗余再补具体**,顺序反了会越改越长。

---

## 为什么需要"次序",而不是一堆规则

原子档各自都对,但同时拿出来会打架:

- [[prompt极简化原则_v1]] 说砍词,[[MJ关键属性三重锁定律_v1]] 说关键属性要三重锁定(正锚 + 负排 + 环境参照,是加词);
- [[反向描述的负面锚定]] 说加 `not X` 更稳,[[负面词计入prompt浓度_v1]] 说负面词不是免费的。

**它们不矛盾,是有先后的**:先把冗余删干净腾出注意力预算,再把预算花在真正会返工的那几个属性上。**顺序颠倒 = 在一条已经臃肿的 prompt 上继续加锁**,这是最常见的越改越糟。

---

## 七步

> 拿到一条跑不对的 prompt,按顺序过一遍。前三步是**减法**,后四步是**加法**。

### 1 · 查冲突(先查这个,它会让后面几步白做)

有没有两个**不能同时成立的锚**?

- 朝代 × 地域(唐制襦裙 + 古泰国宫廷)
- 季节 × 光线(雪夜 + golden hour)
- 年龄 × 气质(少女 + `sultry / languid`,见 [[AI甜妹脸vs复古东方美人]])
- 风格 × 媒介(扁平插画词系 + 摄影词系,见 [[概念锚定_风格置换迭代法_v1]])

**冲突不解决,后面六步全是白改**——模型不会替你取舍,只会把两个锚搅在一起。

### 2 · 删形容词

把 `beautiful / stunning / detailed / amazing / high quality / realistic` 全划掉,看还剩什么。剩下的才是这条 prompt 真正说了的东西。

依据:[[prompt极简化原则_v1]] 第一步四问之二——美化形容词一律砍。

### 3 · 数重复

同一个意思说了几遍?每个意思**只留最准的那一个**。

高发区是画质词群:`hyper realistic / ultra high definition / precise skin texture / cinematic quality / natural skin` 常常是同一件事的五种说法。注意力总量固定,重复词是在从核心元素身上扣预算。

### 4 · 补具体(把第 2 步划掉的翻译回来)

划掉的形容词,一个一个翻译成**相机拍得到的东西**:

- 「漂亮」→ 五官堆叠词块(脸型 / 肤质 / 眼 / 眉 / 鼻 / 唇 / 气质七槽,见 [[东方美人五官堆叠基础句]] · [[清冷少女五官堆叠基础句]] · [[男性五官堆叠基础句]])
- 「有故事感」→ 前中后景层次 + 视线朝向(见 [[AIGC构图意图层_v1]] · [[主体不看镜头律]])
- 内心状态词(`frozen / blankly / exhausted`)→ 可拍摄的外部特征(见 [[姿态指令的不确定性策略]] 补充条款)

自检一句:**这个词,摄影师能拍到吗?**

### 5 · 改打光

把**天气 / 时段词**换成**关系词 + 落点**:

| 换掉 | 换成 |
|---|---|
| `natural lighting` / `sunny` / `golden hour` | `low late-afternoon backlight rim-lighting her hair strands` |
| `soft balanced light and shadow` | `soft bounced fill on her face, not harsh shadows` |
| `dramatic lighting` | `dramatic chiaroscuro across shoulders and upper back` |

依据:氛围 / 时段词在胶片色卡和后期尾巴下会被压平,指望不上;带方向和落点的关系词才生效。见 [[2026-06-13_露背回眸东方美人_chiaroscuro胶片人像复盘]] 方法论 1。

### 6 · 清 `--no`

只留纯画质项:`text, watermark, logo, low quality`。

- **人体 / 皮肤 / 脸 / 手相关的词全部拿掉**(`plastic skin` / `AI generated face` / `blurry eyes` / `extra fingers`)——见 [[负面词计入prompt浓度_v1]]:`--no` 里的词照样被审核 scanner 当 token 读入,在写实真人题上排除效果没拿到,却把浓度推得更高;
- 画面里要保留图标 / 符号时,`logo` 不可进 `--no`(挡字形用 `text, letters, words, numerals` 四词法);
- 需要 motion blur 或浅景深散景时,`blurry` 不可进 `--no`,改 `out of focus face` 只保护主体;
- 真想压住某个漂移方向,优先用 [[反向描述的负面锚定]] 写进正文(`X not Y`),而不是塞 `--no`。

### 7 · 补参数 + 锁关键属性

- **参数一个都不能少**:`--ar` 比例、`--v` 版本、`--style raw`。不写版本跑默认模型,不写比例出正方形。
- **升版本不能只改数字**:见 [[MJ_v8.2_行为档案_v1]]——v8.2 取向偏 bold / 强对比,淡雅克制题是逆风,必须连带压 `--stylize`。
- **只锁"错了就返工"的属性**,用三重锁定(正锚 + 负排 + 环境参照),见 [[MJ关键属性三重锁定律_v1]]。非关键属性不锁,否则把第 2、3 步腾出来的预算又填回去了。

## 实例:第 13 期《月白》

| | 改前 | 改后 |
|---|---|---|
| 词数 | ~130 | ~150(但零冗余) |
| 冲突 | 唐制襦裙 + 古泰国宫廷 | 单一文化锚(唐宫) |
| 主体描述 | `Beautiful` / `realistic Asian beauty` / `detailed face` | 七槽五官堆叠词块 |
| 画质词 | 6 处重复 | 各留 1 处 |
| 打光 | `Cinematic romance film lighting` / `natural lighting` / `soft balanced light and shadow` | `low late-afternoon backlight rim-lighting her hair strands, soft bounced fill on her face` |
| `--no` | 9 词,含 `plastic skin / AI generated face / blurry eyes / extra fingers` | 5 词,纯画质 + `out of focus face` |
| 参数 | 无 | `--ar 3:4 --v 8.2 --style raw --stylize 80` |

出图:发丝逆光银边、暖调暗角、金累丝簪全部命中,即第 5、7 两步的直接产物。

⚠️ **诚实记一笔**:同批五张脸**不是同一个人**。这条 prompt 做的是**气质锚定**,不是**角色锁定**——锁脸要另走 [[角色一致性金字塔]]。体检清单管"这一张对不对",不管"五张是不是同一个人"。

## 边界

- **本档不含新证据**。七步各自的依据都在原子档里,验证状态以原子档为准;本档只主张"这个次序比乱序好",而这一点**本身也未做对照实验** ⚠️。
- **不适用于从零写**:从零写走 [[prompt的四段式结构_v1]] + [[prompt极简化原则_v1]],不必先做减法(还没东西可减)。
- **不适用于需要精密描述的题型**:半人形拟物、视觉欺骗、部件化描述题本来就要长 prompt,第 2、3 步会误伤,见 [[prompt极简化原则_v1]] 的适用边界。
- **第 6 步的"清 `--no`"在非写实题上收益低**:浓度反噬主要发生在写实真人题上,插画 / 动画词系没那么敏感。
