## 一句话（假说）

**moodboard 的行为可能不取决于题材远近，而取决于目标画面里有没有一个「可以被它替换的主体位」。** 没有主体位，它只能给风格；有主体位，它会往那个位置填人——填对是资产，填错是负债。

## 唯一站得住的硬观察

[[moodboard跨题材审美迁移_v1]] 的 ⭐⭐ 二次验证有一个此前未被点明的共同前提：**两个样本（真空包装天空、弄巧绒花）都是静物题，画面里没有人。**

这是可核对的事实，不依赖任何新实验。它至少说明该档「moodboard 迁移的是审美基底不是题材内容」这个结论，**目前只在无人画面上被验证过**——人物题上是否同样成立，那条档案没有样本。

**可能的机制**（未验证）：静物画面里没有位置能安放 moodboard 的人物内容，人物信号无处落地，只剩风格基底渗过来。一旦目标题材也是人物，那个位置就出现了。

## 这一格为什么是空的 ⚠️

原始触发案例是：作者在星官探索里跑了一版加 personalize + 既有「美女写真」moodboard 的图，出图与古典星官题材毫无关系（当代少女、短 bob、露肩、高调白）。当时据此写了一整张「明确指令被覆写」的表。

**当晚核对作者实际使用的 prompt 后，该表全部作废**——那一版跑的**不是**星官 prompt，而是同轮的一条近景清冷少女 prompt。逐项对照：

| 原表断言"被覆写" | 核对结果 |
|---|---|
| `pure black background` → 高调白 | prompt 里没有黑底；正文写的是 `her whole face fully lit ... not lost in shadow`，**高调是 prompt 自己要的** |
| `long black hair` → 短 bob | prompt **没写头发**，属修正三的正常「模糊槽填空」 |
| `exquisite flowing Hanfu` → 露肩现代装 | prompt **没写汉服**，写的是 `white fur collar`，且命中 |
| `celestial rooster` → 消失 | prompt **没有神兽** |
| `gongbi / mineral pigment` → 柔焦写实 | prompt 写的是 `cinematic digital painting` + `soft airbrush shading`，命中 |
| 珍珠链 / 白毛领 / 四芒星＝moodboard 伴生渗透 | **全部写在 prompt 正文里**，属正常执行 |

那一版还**没挂 `--sref`**。逐项核对后，该批出图**几乎全中、零失守**。

**结论：本次探索对「人物题 ＋ 跨族」提供了零证据。** 该格保持空白，等真实对照实验。

## 验证方法（这一格该怎么填）

星官 prompt **一字不动**，moodboard 开 / 关各跑 4 张背靠背：

- 锁 `--seed`（不锁 seed 跑对照等于送命，见 [[multi_sref行为]] 方法论收获 3）
- personalize 全程保持同一状态，别和 moodboard 一起切（否则贡献无法分离）
- 只看两个量：**背景明暗**、**发长**
- ⚠️ 出图后到参数 tag 里核对 `--sw` / moodboard 是否真被接住——[[multi_sref行为]] 记过 web UI 带 moodboard 时会**静默吃掉 `--sw`**

## 顺带的一次同族正面样本（2026-08-24）

那条被误读的近景 prompt，本身是一个干净的**人物题 ＋ 同族**样本：

- prompt：当代东亚少女、清冷气质、珍珠链 + 白毛领 + 星芒、高调打亮
- moodboard：当代美女写真（同族）
- personalize：开
- sref：**无**
- 结果：全项命中，脸质量明显优于此前挂无脸 sref 的那几批

**双重印证**：一是 [[personalize与moodboard分工]] 修正二「同族 → 精准贡献主体维度」；二是 [[参考图缺失维度不可继承律_v1]] 的操作建议——**脸不走 sref，走描述锚定 ＋ personalize**，撤掉 sref 反而修好了脸。
