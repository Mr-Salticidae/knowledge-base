# moodboard 主体争夺律 · v1

> 入档：2026-08-24
> 触发：二十八宿星官系列（参水猿 / 昴日鸡）探索——同一个「美女写真」moodboard，在静物题上是资产，在古典人物题上把整个题材吃掉
> 性质：**综合档**——给 [[moodboard跨题材审美迁移_v1]] 的 ⭐⭐ 结论划成立条件，并统一 [[moodboard拉力陷阱_v1]] 与 [[personalize与moodboard分工]] 修正二、修正三
> 验证状态：机制层 ⭐⭐（由三条现有档案重新归类得出，每条自带独立证据）；本次「跨族人物题」那一格 ⚠️ 含未控变量，见文末「本次样本的诚实边界」

---

## 一句话

**moodboard 的危险度不取决于题材远近，取决于目标画面里有没有一个「可以被它替换的主体」。** 没有主体，它只能给风格（资产）；有主体且跨族，它会直接争夺主体，并**覆写 prompt 里写死的明确指令**（负债）。

---

## 为什么库里三条 moodboard 档看起来互相打架

| 档案 | 结论 | 目标题材里有人吗 |
|---|---|---|
| [[moodboard跨题材审美迁移_v1]] | 美女写真 board 跨题材 → **抬高审美天花板** ⭐⭐ | ❌ 真空包装天空、绒花，**两个样本都是静物** |
| [[personalize与moodboard分工]] 修正二 | 主体匹配 → **精准贡献主体维度** | ✅ 清冷少女，**同族** |
| [[moodboard拉力陷阱_v1]] | 主体被拉成女鬼 | ✅ 苍白汉服少女，**语义相邻** |
| 本次 | 汉服 / 神兽 / 黑底全线失守 | ✅ 古典星官，**跨族** |

三条结论不矛盾，是同一条律的四种落点。判据只有一句：**画面里有没有一个位置，是 moodboard 的主体可以坐进去的。**

- 静物 / 场景 / 图解题 → 没有那个位置 → moodboard 的人物内容无处安放，只剩风格基底渗过来 → **纯资产**
- 人物题 + 同族 → 有位置，且坐进去的正好是你要的人 → **资产**
- 人物题 + 跨族 → 有位置，但坐进去的是**另一个人设** → **负债，而且它会赢**

---

## 「同族」不能只看性别和物种

[[personalize与moodboard分工]] 修正二把边界定为「主体匹配 → 加成」，判据是"主体是不是 moodboard 训练时的目标"。本次样本说明这个判据太粗：

- moodboard 主体：当代东亚年轻女性
- prompt 主体：古典东亚年轻女性（星官神仙）
- **按性别 / 年龄 / 族裔看完全匹配**——照修正二应判"开"
- 实际结果：汉服被换成露肩现代装、古典发髻被换成短 bob、黑底被换成高调白

**判据要细化到人设族**，三项全同才算同族：

| 维度 | 例 |
|---|---|
| 年代 | 当代 / 古典 |
| 身份 | 写真模特 / 神话人物 |
| 画种 | 摄影 / 工笔插画 |

任一项不同即算跨族。

---

## 跨族时它不只填空白，还覆写明确指令 ⚠️

[[personalize与moodboard分工]] 修正三给的心智模型是：

> Prompt 强约束的维度 → moodboard 影响小
> Prompt 模糊或未指定的维度 → moodboard 强势介入

**这个模型只在同族时成立。** 跨族时写死的指令一样守不住：

| prompt 明写 | 出图 |
|---|---|
| `pure black background` | 高调白 ❌ |
| `long black hair` | 短 bob ❌ |
| `exquisite flowing Hanfu` | 露肩现代装 ❌ |
| `large sacred celestial rooster` | 消失 ❌ |
| `gongbi fine linework / mineral pigment` | 柔焦写实 ❌ |

而模糊槽被沿路灌注，**路径可预测**：

- `elegant accessories`（模糊槽）→ 多层珍珠链
- `soft cool divine glow` / `luminous highlights`（模糊槽）→ 四芒星光
- `exquisite flowing Hanfu`（对写真池是外来概念）→ 替换成池子里最近的「华丽衣物」＝白毛领

**这两件事是同一个机制的两面**：修正三说的「留白调味」（资产）与这里说的「跨族污染」（负债），都是 moodboard 往 prompt 的语义空位里灌东西。区别只在于灌进来的是不是你要的。

## 操作口径

写 prompt 前问两句，顺序不能反：

1. **这张图里有主体位置吗？** 没有（静物 / 场景 / 图解）→ 放心挂，走 [[moodboard跨题材审美迁移_v1]] 的资产路线。
2. **有的话，坐进去的那个人跟 moodboard 同族吗？**（年代 / 身份 / 画种三项全同）→ 同族才开，跨族一律关。

跨族又确实想要质感增益，正确做法是**为该题材另建一个 moodboard**，而不是复用现有的。这正是 [[personalize与moodboard分工]] 战略含义 2「多 moodboard 战略」当年预留的位置，本次是它的第一个刚性需求。

⚠️ 与 personalize 分开判：personalize 是底盘，跨题材常驻，本律只管 moodboard。但**古典 / 神话题材下 personalize 也可能是负债**，那是另一条边界，见 [[AI甜妹脸vs复古东方美人]] 2026-08-24 补丁。

## 本次样本的诚实边界 ⚠️

本律的**机制层论证**来自对三条现有档案的重新归类，每条自带独立证据，不依赖本次样本。

但本次「跨族人物题」这一格有一个**未控变量**：作者在同一轮探索里跑过两条 prompt（星官 prompt / 近景调脸 prompt），加 personalize + moodboard 那批**未确认是哪一条**。

- 若是星官 prompt → 上表「明确指令被覆写」整表成立
- 若是调脸 prompt → 只有色调那一行成立（两条 prompt 都写了偏暗偏紫的色调指令，都没守住），发长与服装几行不算数

**不受该变量影响的部分**：色调覆写、脸的原型切换（见 [[AI甜妹脸vs复古东方美人]]）。

**验证方法**：星官 prompt 一字不动，moodboard 开 / 关各跑 4 张背靠背，锁 seed，只看背景明暗与发长。⚠️ 测之前先确认参数被接住——[[multi_sref行为]] 记过 web UI 带 moodboard 时会静默吃掉 `--sw`。
