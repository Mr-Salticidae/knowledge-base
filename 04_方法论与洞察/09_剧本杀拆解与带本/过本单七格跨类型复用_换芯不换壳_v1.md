# 过本单七格跨类型复用：换芯不换壳

> 一句话律：七格描述的是「开本要执行什么」，不是「这是什么类型的本」。跨类型复用时，改**第三格与第六格写什么**，不改格数、顺序与平台口径。

> 入档:2026-11-19
> 来源:《虚拟游戏》过本单（6 人硬核推理 / 四重真相 / 420 分钟）对《草台班子》七格模具的跨类型复用
> 验证状态:单样本（硬核本一例），情感本与机制本未验证

## 一句话

欢乐本的七格壳同时承担三件事——平台备案格式、DM 台上翻页的肌肉记忆、跨本横向对比的基准；三者都与题材无关。所以硬核本也能套，只是要把「复盘」和「机制」两格换成推理本的芯。

## 如何使用

**三个前提**（缺一不可）：

1. 资料包已完整：手册、时间线、真相、线索表齐备，不需要再做 OCR / 转写 / 拆解；
2. 只缺执行单：要的是「三分钟读完、合上能开本」的那一份，不是又一份资料汇编；
3. 体例需与库内已定版一致：平台审的是格式，别另起一套。

任一条不成立 → 走 `juben-deconstruct` 的完整八阶段，不要套七格。

## 换芯对照表

| # | 格 | 欢乐本装什么 | 硬核本换成什么 | 动不动 |
| --- | --- | --- | --- | --- |
| ① | 信息汇总 | 欢乐 / pia 戏 / 无凶案 | 硬核推理 / 还原 / 诡计，难度 ★★★★★，写清「不玩什么」「不适合谁」 | 换字段，不换表 |
| ② | 关系图 | 加害网或债务网 | **旧账网**：同一人多名（用等号/双横线）、旧案凶手、六席与死者的错位 | 换内容，不换格 |
| ③ | 故事复盘 | 加害网 + 互撕弹药 + 三层落差 | **四重反转表**（每重标「被哪条线索推翻」）+ 命案分层（灭门案 / 虚拟案 / 现实案）+ 关键动作全表 | 整体换芯 |
| ④ | 人物表 | 一人一句定位 + 分本卖点 | 一人一句**含动机与手法关键词**，另加一行分本提示（谁拿凶手卡、谁适合沉得住气） | 微调 |
| ⑤ | 带本流程 | 一条编号串 + 3 条红线 | 同结构，但给关键节点打 🔴（小剧场、定版、终局发牌、逐重写白板），并写 AP 口诀 | 加固 |
| ⑥ | 机制 | 敬酒 / 涨粉 / 换角 | **搜证 AP 递减**（4→4→3）、处决与平票、定版时机、结局判定 | 整体换芯 |
| ⑦ | 会员 | 固定一句 | 同 | 原样 |

> ③ 与 ⑥ 是唯一需要重写的两格，其余五格是「换字段」而非「换结构」。

## 硬核本特有红线（比欢乐本多五条）

| 红线 | 为什么 |
| --- | --- |
| 人数写死且注明**不可减人** | 六席对应六条视角，减人即断链 |
| 时长必须闭合到官方区间内 | 硬核本超时是常态，预算表要按环节给出，别只给总时长 |
| 反转层数 = 实际揭晓次数，每重标揭晓动作 | 少一层，DM 就会提前把答案漏出去 |
| **逐重写白板、每重留讨论** | 一口气讲完，全本高潮塌成念稿 |
| 到点才发的牌写清「哪一步发、发几张、只发一次」 | 提前发 = 后面两重直接失效，且不可逆 |

## 体量口径

- 正文 ≤ 6,000 字（**不含**图片引用、图代码块、JSON 等结构化块）；
- 复盘占正文 40–50%——硬核本四重真相会自然顶到区间上沿，属正常，不必为压占比删真相；
- 反过来：文档一旦声明「自包含」，内嵌图片就必须随仓库分发（`.gitignore` 开例外），否则克隆即断图。

## 边界

- 情感本未验证：情感本的「复盘」是情绪落点而非逻辑层序，第③格可能不适用反转表结构；
- 机制本若机制本身构成叙事（阵营、推理以外的资源博弈），第⑥格 3–5 条可能不够，需评估是否回到完整流水线；
- 无资料包时不要用本方法——七格是**收敛**工具，不是**拆解**工具。

## 实战数据

| 本 | 规格 | 数据 |
| --- | --- | --- |
| 《草台班子》 | 6 人 / 190 分钟 / 无凶案 | 首版 9,400 字 → 手删至 2,600 字 |
