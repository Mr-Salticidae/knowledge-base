# 过本单七格收敛：把「已知」压成「要用」

> **一句话律**：执行型文档的篇幅，不由「我知道多少」决定，由「台上那一秒会翻到哪几格」决定。
> 第一稿写全是必要的，**交出去之前必须再删一遍**；删的标准不是准不准，是用不用得上。

> 入档：2026-11-19
> 验证状态：⚠️ **单样本**（《草台班子》一本，一次实战即大成功）
> 来源：`juben-happy-deconstruct` skill 的封装现场

---

## 为什么第一版必然过载

写本的人手里有全套资料：手册、角色本、线索卡、物料清单、软件操作路径。写作时这些信息**同时在脑子里**，落笔就会按「完备」排序，而不是按「现场用得上」排序。

《草台班子》首版过本单 9,400 字，七格俱全、事实无错，交给本人后**被手工删到六成**。删掉的四类东西，没有一类是错的：

| 删掉的 | 为什么留着没用 |
| --- | --- |
| 道具清单、BGM 编号、扫码步骤 | 现场翻手册比翻过本单快，塞进单子只是把手册抄了一遍 |
| 逐字台词、暖场话术、彩排提醒 | 手册里已有；过本单写第二遍，改口径时两处会打架 |
| 角色戏份星级、难度星级、道具列 | 分本时真正用得上的只有一句话 |
| 机制的非核心分支（罚则细则、边界情况） | 一场能用到的规则不超过 5 条 |

**共同点**：它们都正确，但都不在「读单—开本」这条动作链上。

## 七格模具

| # | 格 | 体量 |
| --- | --- | --- |
| ① | 剧本信息汇总（含**不适合谁**） | 一张表 8 行 |
| ② | 人物关系图（SVG，非 ASCII） | 图 + 12 行 |
| ③ | 故事复盘 | **全文 40–50%** |
| ④ | 人物表（一人一句） | 6–8 行 |
| ⑤ | 带本流程（一条编号串 + 3 处红线） | 1 段 + 5 行 |
| ⑥ | 核心机制（3–5 条，每条有判罚口径） | 每格 ≤ 8 行 |
| ⑦ | 会员一句话 | 1 行 |

**只有第 ③ 格允许长。** 欢乐本没有凶手，复盘的对象是「以为在看什么」与「实际在发生什么」的落差——反转层序、关键动作、结局落点，少一层现场就答不上话。其余六格都是索引，不是内容。

## 削的优先级（越靠前越先砍）

1. 物料清单、软件操作、BGM 编号 → 挪进现场速查卡
2. 逐字话术、台词、彩排提醒 → 手册已有，只留指针
3. 戏份 / 难度 / 道具三列 → 压成一句话
4. 机制分支与边界 → 只留主规则 + 判罚
5. 结局抒情段 → 留最后一句金句

**永远不砍**：人数硬约束、时长闭合、反转层序、终本发放方式、必须强行收的节点。

## 两个验收动作

| 测试 | 做法 | 判据 |
| --- | --- | --- |
| 三分钟测试 | 交给一个没读过手册的人 | 三分钟内能判断「这本能开」 |
| 合上测试 | 自己合上文件 | 能凭那条编号串报完全场 |

做不到，就是又多写了一份资料汇编。

## 边界

- 适用于**演练型交付**：开本单、操作手册、带教文档、教程。这类文档的价值在「当场能不能用」，不在「覆盖全不全」。
- **不适用于责任型文档**：合同、法务意见、验收报告、安全规程——那类文件里，完备本身就是责任，删减是风险而不是优化。
- ⚠️ 单样本。七格的具体切法来自《草台班子》一本，换本（情感本 / 机制本）可能需要换格，但「先写全、再按动作链删」这条次序可迁移。

**补充（2026-11-19）**：第二本《虚拟游戏》（6 人硬核推理 / 四重真相）验证了这条删减律可跨类型迁移，同时把「换格」这个悬念收窄了——**七格本身不用换，要换的只有第 ③ 格与第 ⑥ 格的内容**；篇幅口径也补上一条：字数按**正文**计，图片引用与图代码块不算正文、也不做占比分母。详见 [[过本单七格跨类型复用_换芯不换壳_v1]]。原「单样本」警示保留，情感本仍未验证。
