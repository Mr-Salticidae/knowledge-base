## 排版判断

- **底图是高调近白，所以主标走深墨而不是浅色**：深冷墨宋体 +「白柔光晕」垫底做分离；套暗调封面的骨白/暖金标题会直接糊在白背景上。
- **一张图里两种字色，按所压区域的明暗分**：主标压左侧冷白留白 → 深墨；钩子句压左下黑衣暗部 → 米白 + 极淡暗投影。第一版把楷体题跋放在主标右侧，压到了头发暗部，深字直接吃掉，已废弃。
- **强调色取自画面本身**：绯红细线 + 朱砂闲章呼应发带与格纹红，不引入外来色。
- 不压暗角——高调底压角会破掉冷白通透感。
- 封面只有作品名 + 一句钩子，无作者名 / 栏目名 / 期号 / 英文。
