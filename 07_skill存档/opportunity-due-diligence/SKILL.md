# 机会尽调（副业招募 / 兼职外包 / 合作邀约）

把一份来路不明的赚钱机会，核成一份**当事人拿了就能自己做决定**的尽调笔记。

## 适用与不适用

**适用**：副业招募、内容代剪/代运营外包、代理与分销邀约、拉新返佣、地推、各类「低门槛高回报」项目。

**不适用**（碰到直接说明并停手）：
- 正式雇佣 offer 的薪资谈判——那是另一套；
- 投资标的、理财产品、加密资产——**不提供个性化投资建议**，说明自己不是持牌顾问，只能帮着核事实；
- 明显的涉刑活动（跑分、洗钱、刷单诈骗）——直接指出性质，不做「划不划算」分析。

## 核心心法

> **「是不是骗局」和「值不值得做」是两个独立的问题，必须分开下结论。**

绝大多数人只问「靠不靠谱」，把这两件事揉成一个，于是得到的答案要么是「小心有诈」（没用），要么是「看着挺正规」（更危险）。

分开之后结论才有操作性。最常见的真实答案是第三象限——**不是骗局，但极不划算**：

|  | 值得做 | 不值得做 |
|---|---|---|
| **不是骗局** | 真机会（少见） | **低价外包（最常见）** |
| **是骗局** | — | 直接出局 |

一个项目「不收你钱」不等于「不浪费你时间」。骗局骗的是本金，低价外包吃的是时薪和机会成本，**后者数量级上远比前者常见**。

## 四步查证法（顺序不能换）

### 第 1 步 · 查甲方是否存在

搜平台真名、上线时间、运营主体、包名/域名/备案。

- **查得到** → 说明不是凭空捏造，往下走；
- **查不到** → 直接出局，后面三步不用做。

顺带确认招募文案对甲方的描述是否属实（「XX 平台」是不是真的存在、是不是真的在做这块业务）。**甲方真实 ≠ 招募方与甲方有关系**——这两件事要分开记，第 4 步会用到。

### 第 2 步 · 查行业对标价

搜同类业务的**公开单价**：公开 affiliate 计划、网盟 offer、行业报价、同行帖子。

拿到对标价后画出转包链，标出当事人在第几格：

```
甲方 → 广告渠道/网盟 → 合作方 → 组织者 → 当事人
```

给到当事人的价格显著低于对标价，**中间抽了几手一目了然**。这一步的产出不是「他黑心」，而是「当事人站在链条末端，出的是全部劳动，拿的是被削过的价」——一个可验证的位置判断。

**推论**：如果当事人具备跑通全链路的能力（自有账号、自有渠道），那他根本不该走这个中介，直接接公开 offer 单价高一倍以上。凡是招募文案里写着「能承担的环节越多分佣越多」，都要把这句话反过来讲一遍给当事人听。

### 第 3 步 · 查是否前置收费

**这是骗局与低价外包的分水岭，二值判据，效率极高。**

前置收费的形态（一个都不能有）：课程费、授权费、加盟费、设备押金、保证金、办手机卡、买流量、买号、「先充值才能提现」、「新用户充值 XX 元才算有效」、提现门槛。

- **有任何一项** → 判定为骗局家族，直接建议出局。国内被央视及主流媒体反复曝光的「短剧推广」「零基础月入过万」类骗局，核心特征高度统一就是先收费；
- **一项都没有** → 它不是那类骗局，**别一棍子打死**，继续第 4 步。

诚实地把这一条说出来很重要：当事人往往已经被「这是不是传销」的焦虑占满，先给一个干净的判定，他才听得进后面更重要的第 4 步。

### 第 4 步 · 查能否验证结算依据 ⭐

**最容易被忽略、也是最决定性的一条。**

问的是：**结算数据在谁手里，当事人能不能对账。**

- 计价单位的定义写清楚了吗？（「有效下载」「有效客户」「有效播放」——**定义空着的那个词，就是整份协议里最值钱的词**，每加一个限定条件，收入砍一半）
- 当事人能看到原始数据吗？账号归谁、后台谁能登、归因数据谁出？
- 有没有书面的单价与结算规则？

> **对不上账的计件工作，单价写多少都没有意义。**

**特别注意「统一处理」类话术**。「账号和发布由项目方统一处理」「素材我们统一分发」听起来是福利（你不用操心），实际含义是三件事：

1. **结算数据由对方单方面掌握**——不是怀疑对方人品，是结构上当事人没有对账能力；
2. **当事人无法影响转化结果**——转化取决于账号权重、发布策略、落地页，这些都不归他管，此时「多劳多得、没有保底」翻译过来就是**风险全部由劳动方承担，而劳动方是链路里唯一影响不了结果的人**；
3. **零资产沉淀**——干半年，没账号、没粉丝、没作品集（作品挂在别人号上）、没可证明的履历，只剩一门手艺。

## 三个必做的附加动作

### A · 自己把时薪算一遍

对方永远给「单价」和「上不封顶」，从不给时薪。**必须自己按乐观口径算完整链条**：

```
每天产出 N 件 × 单件耗时 → 每天工时
每件带来的曝光 × 转化率 → 每天有效结算数
× 单价 → 日收入 ÷ 工时 = 时薪
```

按**乐观**口径算（转化取行业上限），算出来的时薪如果还低于当地线下兼职，结论就非常干净了。测算表要摆进笔记里，让当事人自己看着数字点头，比你下判断有用。

### B · 找宣传口径与免责口径的落差

海报/朋友圈话术 vs 正文小字，通常是两套：一套负责让人报名（「轻松创收」「抢占风口」「不出海就出局」），一套负责在赚不到钱时免责（「没有保底，请以副业心态参与」）。

**这个落差本身就是证据**，把两段原话并排放进笔记（用 `.grid2` 两栏对照），不用多评论，读者自己会得出结论。

### C · 问中位数，不问最高值

给当事人的必问清单里，一定有这一条：**「上一批参与的人，月收入的中位数是多少？」**

对方只肯给「某某月入 X 千」这种个案 → 直接判负。这是所有招募方最难绕过的一问。

## 产出体例

写成一篇**独立可读、可直接转发给当事人**的尽调笔记，存 `E:\knowledge-base\08_对外分发\`。

### 结构

```
标题（用当事人会问的那句话，如「XX 这个副业能做吗」）
导语：这份招募说的是什么 + 一句话结论
一句话结论
一、事实核查：哪些是真的        ← 判定表，先把能查证的查证掉
二、真正的问题：不是骗不骗，是划不划算   ← 分条，含转包链、时薪测算、口径落差
三、报名前必须问清的 N 个问题     ← 编号清单，标出哪几条答不上来就该走
四、要参与的话，这样参与        ← 止损实验 + 红线 + 心理定位 + 更优替代路径
附：可复用的四步查证法
```

### 硬规则

- **称谓一律第二人称**。这篇是直接转发给当事人读的，正文出现「学员/同学/他」等于把读者写成第三方，读着别扭。文件名也不要带 `_学员版` 这类层级标签，层级只写在索引里；
- **不替人做决定**。给判断框架、给必问清单、给止损方案，最终做不做是他的事。不要写「建议你别去」这种句子，要写「答不上第 1、2、5 问就不用做了」这种可执行判据；
- **给替代路径**。否定一条路的同时给出更优的那条（公开 offer、自有账号、能力可迁移的部分），否则这篇只是泼冷水；
- **给出真实的正面项**。不收费就写不收费，平台是真的就写是真的——只挑负面写的尽调没有公信力，当事人下次就不来问了；
- **明确「止损实验」而不是「别做」**。给一个有边界的验证方案：做 N 件 / 两周，只验证「第一次结算是否按约到账 + 数据是否对得上」，对不上立刻停；
- **来源可查**。文末列依据来源，标注哪些数字是公开资料估算、非官方口径。
