# 文本模板一使用说明

这是当前旧版课程预告文本格式，对应 `text-template-1`。

## 基础信息阶段

- 每个课程先写班级名称。
- 下一行写“日期 + 课程名称 + 讲师名称”。
- 录播课程使用普通黑色正文。
- 直播课程整行使用红色加粗文字，并以“（直播）”结尾。
- 本阶段不加入课程工具、作业和课程目标；交付用户确认后停止。

## 详细介绍阶段

- 仅在基础信息得到用户明确同意后追加。
- 保留班级标题和基础课程行。
- 直播课程写明上课时间、主题、讲师、工具、可选作业和课程目标。
- 录播课程写明可观看时间、讲师、工具、可选作业和课程目标。
- 历史介绍中的日期和时间不能直接沿用，必须替换成本次课表或用户确认的时间。

## 数据不足时

- 直播时间不明确：停止并询问。
- 课程详情有多个同名候选：列出来源并让用户确认。
- 课程目标为空：不得进入海报制作。

## 修改默认模板

新增文本模板不会自动成为默认模板。只有用户明确说“将文本模板二设为默认模板”时，才修改文本模板注册表的 `default_template_id`。
