# 海报模板一使用说明

这是 `poster-template-1` 的 Skill 内置基准资产。画布为 1080×1835，课程标题位于智能对象中，日期、时间、直播/录播标签、课程目标、教师姓名和人物均保持可编辑。

- 优先在 `课程预告ps/` 中查找内部课程标题精确匹配的可复用 PSD。
- 每个候选 PSD 都必须先检查；历史模板一 PSD 的图层结构可能不同，不能只凭文件名或直接套用基准图层 ID。
- 候选结构与 `contract.json` 一致时，才允许使用统一脚本修改。
- 标题保持居中，目标中心为智能对象横坐标 469px，最大偏差 15px。
- 课程目标与日期时间区域至少保留 20px，不得被内框或页脚遮挡。
- 人物必须来自项目设置的 `人物/` 文件夹，只保留透明背景的人物主体。
- 长期课程 PSD 保存到 `课程预告ps/`，按课程名称命名；最终 PNG 保存到当日日期文件夹。

Skill 中只内置一个已验证基准 PSD，用于新课程缺少精确课程 PSD时的受控派生。历史课程 PSD 库不会整库复制进 Skill。
