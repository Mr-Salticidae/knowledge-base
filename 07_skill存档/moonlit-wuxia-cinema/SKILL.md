# 月夜国风幻想武侠镜头

生成或诊断“明月、武侠人物、双向飘动服饰、环境边缘高光”类型的国风幻想CG图片，并把用户确认的图片发展成15秒视频提示词。默认媒介是国风幻想2.5D/2D CG插画：以平面化剪影、绘制式布面和水墨虚实组织造型，以电影化逆光、景深和少量体积建立空间；不是写实摄影、物理写实3D、欧美奇幻概念图、普通游戏角色渲染或日漫赛璐璐。目标是让人物具有神秘感，同时让场景保持华丽、通透、明暗完整、有层次；高光醒目不等于全画面明亮，保留暗部也不等于整体低曝光。

## 接收任务

先确认用户要的是：

- **新图生成**：把场景、人物、动作和道具整理成可执行图片提示词，并使用可用图片模型生成。
- **风格复刻**：以参考图的低频亮度场、色彩场、焦点层级和构图关系为母版，更换或保留用户指定内容。
- **镜头诊断**：比较参考图与结果图，定位整体压黑、全画面同焦、亮部不足、服饰结构错误或构图漂移。
- **提示词交付**：只输出完整提示词与可复用模块，不擅自生成图片。
- **图片到视频**：先完成并确认画面图片，再让用户选择一个视频模板，最后根据确认图片制作15秒视频提示词。
- **已有图片制作视频提示词**：用户已经提供认可的图片时，可跳过图片生成；若用户同时明确模板编号，直接进入视频提示词阶段。

用户已经指定的人物数量、姿态、道具、场景、画幅和主体位置均为不可变量。不要添加无关角色、武器、建筑或叙事元素。

## 图片到视频的阶段流程

严格按阶段推进，不在图片尚未确认、模板尚未选择时提前合成最终视频提示词。

### 阶段一：完成画面图片

- 用户没有提供已确认成图时，先按本技能的镜头、光影、服饰和构图规则生成或复刻图片并进行验收。
- 图片交付后停止视频提示词写作，展示四个模板的名称、运动规模与风险，让用户选择。
- 用户明确说图片已经满意、直接使用现有图片或上传成图时，将该图视为已确认首帧并跳过本阶段。

### 阶段二：选择视频模板

向用户提供以下四项，不擅自替用户决定；若用户已经指定编号则不重复询问：

1. **中心锚定型原地剑舞**：严格沿规范母版的十个时间段完成预备、抽剑上撩、横扫、半转回撩、三朵剑花、低位削挑、唯一整圈旋身、直刺转斜劈、五式高潮与终式斜斩；人物始终在一步范围内。
2. **中心区域多向攻防**：严格沿规范母版的八个时间段完成三色水墨围攻、银白符页防守、诱导青色力量、束缚压缩、融合控制及三方持续交锋；人物无武器。
3. **持续位移型仙侠剑舞**：严格沿规范母版的十一个时间段持续向右、远端与高处推进，依次切开月华光幕、月影、光靶、光帘、浪墙、光环、镜片、月光弦与终式月华镜；视觉强且一致性风险最高。
4. **原地行礼舞剑（动态环绕版）**：先短促行礼，再用一步内的快速出剑、上撩、横扫、回撩、短刺和终式展示人物；镜头持续向右环绕，大幅追随剑势升降，并在近景与全景间连续快速推拉。

四个模板均为15秒。用户需要完整模板或已选择其中一个时，读取 [references/video-prompt-templates.md](references/video-prompt-templates.md)。模板一、二、三还必须读取该文件指向的对应规范母版；模板四继续以模板文件正文为准。

### 模板一、二、三的分镜保真规则

模板一、二、三不是“动作类型示例”，而是从用户提供的参考提示词抽取出的固定分镜母版。以下内容均为不可变量：

- 每个时间段的起止时间、段数和总时长；
- 人物动作的顺序、数量、发力方式、移动方向、起势、接续、受力结果与收势；
- 与动作同步的运镜方向、景别变化、升降、环绕、推拉、震动、慢动作和结束方式；
- 人物在画面中的位置、运动轴线、前后景关系、主次焦点和动作完成时的构图关系；
- 外部攻击、障碍或互动目标出现的时间、数量、空间方向、接触顺序和人物动作造成的结果类型。

必须根据当前首帧替换场景相关内容：环境元素、粒子、地面/水面介质、倒影、花叶、云雾、建筑细节、外部攻击或障碍的视觉载体，以及它们与剑风、脚步、衣摆或能力产生的具体互动表现。原参考中的枫叶、水面、月华光幕等不是固定素材；当前图只有桃花时，把“枫叶被剑风卷起”替换成同一时刻、同一方向和同一运动结果的“桃花瓣被剑风卷起”，不得继续生成枫叶。当前场景没有水面时，水面涟漪或倒影扰动应改写为亭面花瓣、云雾、尘光或其他首帧真实存在的介质响应。替换场景载体时保留原分镜的因果时机、方向、强弱和构图功能，不保留不属于当前图片的物体。

此外只允许替换不会改变分镜骨架的变量：首帧引用标签、人物身份与外观、服装和场景名称、全局媒介、色彩与光影。不得合并或拆分时间段，不得改写时间码，不得删减、增加、概括、重排或替换人物动作，不得因“降低崩坏风险”而简化编舞，也不得为迁就首帧而把抽剑改成直接挥剑、把腾跃改成站立或把持续推进改成原地表演。

在套用模板前先做兼容性检查。若首帧中的武器状态、角色动作能力、可移动空间或朝向无法执行规范母版，停止生成最终提示词并明确指出冲突；场景素材不同本身不构成冲突，应先按上述规则替换互动载体。将模板转换为 MiniMax H3 或其他模型格式时，只能改变字段结构、引用标签和语言表达，并同步使用已经适配当前场景的互动内容；人物动作、时间规划、运镜、构图和因果时机必须逐段一一对应。

### 阶段三：根据确认图片制作视频提示词

1. 将确认图片作为0.00秒实际第一帧与唯一视觉锚点，先锁定人物身份、脸型、发型、身形、服装结构和颜色、武器数量与场景结构。
2. 只把图片中稳定可见的媒介、暗部与中间调、主光方向、局部高光、色彩搭配和材质关系概括为视频全局约束；禁止把静态图片提示词逐字搬运进视频提示词。
3. 写明画幅、景别、焦段、光圈观感、机位、焦点、运镜幅度与是否连续镜头。
4. 按所选模板分段。模板一、二、三逐段保留对应规范母版的时间码、人物动作、运镜和构图；把每段中的环境元素及互动反馈改写为当前首帧真实存在的桃花、云海、亭面、栏杆、光影或其他场景介质。模板四按其正文执行。每段使用一个连续段落，依次写清人物动作、镜头响应、当前场景因动作产生的变化。
5. 最后给出限制提示词和音效设计。只保留会改变模型判断的约束，不堆叠“8K、超高清、极致细节”等空泛质量词。
6. 默认只交付视频提示词；仅当用户另外明确要求且存在可用视频工具时才实际生成视频。

## 核心视觉原则

### 风格必须先锁定

默认风格锚点写为“国风幻想2.5D/2D CG插画、东方水墨式虚实、电影化逆光与景深”。以平面化暗色剪影、书法式轮廓、绘制式布面和概括的色块组织人物与环境；体积只服务于轮廓转折和受光关系，不追求真实皮肤、真实丝绸或物理布料模拟。禁止仅写“国风写意3D、电影感写实、优雅写实、风格化写实、cinematic concept art”，这些表达会让模型滑向偏摄影或游戏渲染。

风格验收看三个可见结果：人物首先读成概括的2D暗色剪影；服饰由绘制式连续色块、书法性边缘和透光亮面组成，而不是写实纱裙；前景与背景以水墨式虚实和电影景深分开，月亮、环境边缘及衣袍亮面具有插画式华丽光效。三者缺一，不判定为风格成立。

“唯美”是硬性视觉结果，不是气氛形容词：高光边缘带柔和辉光，亮暗过渡平滑，人物与衣袍形成舒展的S形或扇形流线，冷月蓝与暖琥珀彼此映衬；保留深影但不使用生硬英雄式强对比、金属描边、霓虹发光、颗粒化纹理或过锐月面。若画面先读成冷峻史诗风、游戏海报或写实夜景，即使元素齐全也判定风格失败。

### 高光不等于亮场

不要把“神秘感”理解为整体低曝光，也不要把“华丽”理解为整体提亮。使用通透的中低调影调：月亮、环境边缘、衣缘和水面反射提供明确可见的局部高光；深靛天空、黑发、面部背光面、衣袍内侧、树干岩石与画面边缘提供暗部锚点；人物白衣、云雾和主要环境的大部分仍处在清楚、有颜色的珍珠灰、月蓝灰或暖灰中间调。禁止使用“dark and midtone-dominant exposure”“整体暗调”“克制到几乎不可见的高光”等会诱导全局压暗的提示表达。

除非用户明确排除月亮，月夜武侠画面默认保留一轮可识别的明月作为宽阔、柔化、低局部对比的背景光场与构图锚点；参考图含月亮时不得擅自删除。明月通常位于人物后方或后上方，与人物轮廓紧密关联，用于照亮衣袍、景物边缘和雾气，而不是只做装饰圆盘。月亮可以具有高亮度，但不得成为最锐利、局部反差最大或第一眼最抢视线的对象；月面纹理必须弱于人物与衣袍的主要明暗边界。

人物面部暗光的目标是让观众看不清完整五官，只保留额头、鼻梁、唇线、下颌、发际或侧脸外轮廓，使身份含蓄而神秘。参考图式人物不仅面部暗，上半身内部也应大面积处于暗部：头、颈、肩、胸与手臂核心形成连续暗色剪影，只允许发际、鼻梁、下颌、肩缘、手和剑柄出现少量分离光；亮度重心落在下半身飘动服饰而不是胸脸。禁止为了隐藏人物而压暗月亮、花叶、云雾和整个场景。

### 朦胧不等于模糊

人物外轮廓、主要发束、手、关键道具和服饰主褶线保持清楚。唯美朦胧感来自亮部光晕、空气透视、前后景失焦和自然焦点渐落，不使用全画面模糊或全局低对比蒙版。

当需要“白衣局部柔光”表现时，只降低人物头部、肩颈、胸前薄纱与阔袖受逆光区域的局部微对比，让上半身像被月光轻柔包裹；腰线、握剑手、剑鞘、身体主轮廓与裙摆主褶仍保持清楚。面部不能完整展示给观众，朦胧层只帮助隐藏五官，不能把人物变成失焦人影。

### 人物是唯一主焦点

人物通过位置、轮廓、明暗对比和清晰度成为焦点。靠近镜头的遮挡物柔化，远处月亮、建筑和植被轻柔失焦；环境仍需保留可读层次，不能完全糊成色块。

“前景深＋背景深”是必需镜头语言，表示焦点前后都存在清楚的距离落差：近镜头必须有一层明显柔化的石块、花枝、柱影、水纹或反光作为前景深；人物处于唯一清晰焦平面；人物之后必须有可辨中景和进一步柔化的月亮、树影、建筑、山水或云雾作为背景深。禁止只有一个前景小物但全图同焦，也禁止背景只有空色块而没有纵深层次。

### 视觉注意力顺序

先设计观众的注视路径，再设计亮度：

1. **第一视觉锚点：服饰塑形高光**。最强的局部明暗反差和暖色饱和度落在人物衣袍，沿肩、手臂、收束腰轴、前方遮身层与后方长摆连续组织，第一眼必须读到人物的纤细、飘逸和华美。
2. **第二视觉锚点：神秘侧脸与暗色上身核心**。完整五官隐藏，只用窄轮廓光确认朝向、动作和气质。
3. **第三视觉锚点：柔化明月**。月亮是包围人物的冷色光源和背景大形，不与衣袍争夺锐度与局部对比。
4. **第四视觉锚点：环境高光簇**。花叶、树干、崖石、水面或建筑只在选择性边缘形成次级亮点，负责框景和呼应。
5. **空间支撑：前后景虚实**。近景和远景制造距离，不成为独立主题。

若第一眼先看到月面纹理、云海或整棵树，而不是衣袍高光塑造的人物，则无论内容是否完整都判定失败。

### 服饰以大结构建立华丽感

参考图式服装不是贴身长裙加单一后摆，而是“暗色人体核心＋前方遮身飘片＋后方横向长摆”的双向结构。窄肩、修长颈线和收束的上身轴线暗示纤细身形，但前方阔袖、披帛或外袍长片从手臂、腰侧和腹前向前下方飘落，主动遮挡胸腰、髋腿和足部；后方裙摆与外袍则向风向水平展开，形成两至三组宽阔弧面。前垂与后掠布面共同包围暗色人物核心，形成S形或旋涡式大轮廓。不得要求腰身始终完整暴露，也不得只生成一条写实婚纱式拖尾。

华丽感来自绘制在大布面内部及边缘的三至五组连续宽带或块状透光高光：主光路从肩缘或扶剑手进入，在腰轴附近收窄，再向前方遮身层、下垂裙摆和后方长摆扇形展开；亮带之间保留深色缝隙。迎光布片可出现琥珀金或月白亮面，背光布片保持深灰褐色，亮暗穿插；高光约占服饰可见面积30%–45%，并拥有全画面最强的局部对比。它们必须在缩略图下直接勾勒纤细身形与裙摆弧线，而不是只装饰远端拖尾、均匀描边或模拟金属/写实丝绸反射。

全景指头部到衣摆末端的完整人物轮廓，不等于必须露出脚。参考图式及地阔摆应完全遮住足部，以连续的大轮廓维持飘逸感。

## 工作流

1. **锁定内容**：记录人物数量、全景/半身、精确朝向、动作、道具位置、场景、风向、画幅、主体位置与主体占比。正侧面必须写成相机与人物肩线近似垂直的90度纯侧面，不能退化为四分之三侧面。用户指定拔剑时，必须写成一手握剑柄、一手稳住剑鞘、剑身局部出鞘的可读动作，不可退化为持剑站立。
2. **先建注意力地图，再建亮度地图**：先锁定“衣袍塑形高光 → 神秘侧脸 → 柔化月亮 → 环境高光簇 → 景深支撑”的注视顺序，再分别定义面部选择性暗影、衣袍主光路、月亮柔光场、环境轮廓反光、人物与环境中间调、框景暗部与反射明暗间隔。采用双光源逻辑：冷色月光从后上方提供宽阔逆光和轮廓分离，暖色侧后掠射光穿过花叶或建筑落在衣袍与环境边缘，负责塑形和唯美暖光；不增加正面补光。先确保天空、云雾、白衣和主要环境具有可读中间调，再布置暗部锚点与高亮落点；禁止用“整体暗调”或“整体明亮”代替分区。
3. **选择镜头**：根据人物是静立、舞剑还是高速移动，确定焦段、机位高度、景别、透视压缩和运动表现。人物主导时以“身体、头发与全部飞扬衣袍的合并剪影面积”验收45%–55%，通常占画面高度70%–85%、宽度50%–70%，其中飞扬裙摆贡献合并轮廓的55%–70%；避免模型把占比误读成人物高度或把人物缩成风景点景。
4. **设计构图**：默认保留可见但柔化的明月作为人物后方背景光场，用月亮、林木、建筑或水岸形成近距离框景；让暗色人物上半身压在月亮或亮雾之前获得轮廓分离。给前垂服饰和后掠长摆分别留出空间：人物前方保留下垂、回卷和遮身布片，人物后方保留水平展开的大弧面。控制风景负空间，云海、湖面或空天空不能成为比人物更大的独立主题；悬崖云海场景应让桃枝、树干、崖沿靠近人物形成中景包围，并把云海压成柔化的背景层。
5. **设计服饰**：先定义暗色人物核心，再分别定义前方遮身层、后方长摆层、阔袖/披帛、剑鞘与高光分布。前方布片遮挡部分胸腰、髋腿与足部，后方布片负责横向面积；两组布面方向不同但受同一风场约束。不得退化成贴身白裙、单一婚纱拖尾、均匀半透明纱或大量碎条。
6. **设计景深**：强制建立“前景深＋背景深”：近镜头柔化遮挡层通常占画面边缘或下部约5%–12%，允许被画框裁切；人物处于唯一清晰焦平面；人物之后至少有一层可辨中景和一层明显柔化的远景光场。月亮降低表面细节与边缘锐度，远树、云海和环境亮点出现受控光晕与焦点渐落。前景小石块即使现实尺寸小，也要因贴近镜头产生约4%–7%的柔化视觉体量，不能成为清晰地面摆件或小到无法建立距离。
7. **生成与验收**：检查人物、道具、构图、亮暗比例、服饰结构、焦点、前后景和反射；只对一个明确偏差做一次定向迭代。

需要具体镜头参数、亮度比例、构图公式、参考图式服装结构或完整提示词时，读取 [references/style-system.md](references/style-system.md)。对外交付提示词默认使用八项短格式：景别、光影效果、构图、场景、主题、色调、镜头参数、材质；只写影响结果的硬约束。

## 边界

本技能只负责美术指导、镜头和生成表达。重复纹理、噪点、过锐等生成伪影的预防与修复不写入本技能；遇到此类任务时改用专门的伪影修复技能，并保持本技能定义的光影与构图不变。

## 验收标准

- 人物是唯一视觉焦点，头部至衣摆末端的完整轮廓、动作和道具符合用户要求；及地阔摆按设计遮住足部。
- 第一眼必须落在衣袍塑形高光所勾勒的人物，而不是月面纹理、云海、湖面或整棵树；明月是柔化低局部对比的背景光场。
- 默认风格首先读成国风幻想2.5D/2D CG插画：平面化暗色剪影、绘制式布面与书法性边缘明确，同时保留电影化逆光和空间；不得滑向物理写实3D、摄影、欧美游戏概念图或日漫赛璐璐。
- 参考图或月夜场景所需明月不得丢失；月亮必须参与人物、服饰和环境边缘的光影塑造，但不得成为最锐利或局部反差最大的对象。
- 面部完整五官不可清楚辨认，但侧脸或轮廓仍优雅可读。
- 场景既不因面部暗光而整体死黑，也不因多层高光而整体发亮；暗部与有颜色的中间调构成主体，高光只负责视觉落点和轮廓塑形。
- “前景深＋背景深”明确成立：近景柔化遮挡、人物唯一清晰、中景可辨、远景与月亮自然柔化，不能全画面同焦。
- 人物上半身可有受控的局部光晕与较低微对比，但完整五官不可辨认，腰线、手、剑和裙摆主褶仍清楚。
- 服饰具有暗色人物核心、前方遮身飘片、后方横向长摆、阔袖/披帛与及地阔摆；前后两组布面共同形成S形或旋涡式轮廓，足部完全隐藏。
- 三至五组宽带塑形高光必须从肩/扶剑手经过收束腰轴，延伸到前方遮身层与后方长摆；高光占服饰约30%–45%，以全画面最强局部对比直接修饰纤细身形，禁止随机亮纹、均匀描边或金属质感。
- 纤细身形由窄肩、修长颈线和收束的上身轴线暗示，不要求腰身完整外露；人物头颈肩胸大面积处于暗部，服饰亮度重心在下半身及前后飘片。
- 树叶、花簇、崖石、屋檐或水岸具有与主光方向一致的边缘反光，环境不能只剩无光暗块。
- 构图稳定，主体轮廓与主光源关系清楚，无新增文字、logo、水印、界面或无关元素。
- 人物及全部衣袍的合并轮廓在人物主导镜头中占画面约45%–55%，高度约70%–85%、宽度约50%–70%；风景负空间不得把人物降格为点景。
- 画面整体必须先读成柔美、通透、含蓄的月夜幻想，而非冷硬、史诗、金属化或游戏海报式视觉。
- 视频提示词使用已确认图片作为唯一首帧锚点，人物、服装、武器、主光和场景关系全程稳定。
- 模板一、二、三的输出必须在时间码、人物动作、动作数量与顺序、运镜、构图、接触时机和结果类型上与规范母版逐段一一对应；任一项被合并、删减、新增、替换或重排，均判定失败。
- 每段环境互动必须来自当前首帧：当前图是桃花场景时不得残留枫叶，当前图没有水面时不得残留水纹或倒影扰动；环境载体虽可替换，但出现时间、受力方向、响应强弱和构图作用必须与对应动作同步。
- 所选模板、总时长和时间段连续无缺口；每段均包含人物动作、运镜和环境反馈，且运动规模符合模板定位。
- 视频全局风格是对图片视觉关系的概括，不是静态图片提示词的逐字复制；限制提示词与音效设计完整而克制。
