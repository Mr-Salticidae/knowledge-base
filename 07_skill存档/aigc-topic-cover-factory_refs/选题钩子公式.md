# AI 爆款选题钩子公式

从对标 11 份真实文案反推出来的结构。这些不是拍脑袋编的模板，是已经跑过量的句式。

## 怎么用

要 20 个选题，**不是**从一个公式里灌 20 遍，而是**至少覆盖 6 个不同公式**。
同公式的选题在信息流里长得一样，A/B 测不出东西来。

每个选题产出四样：`lines`（分行文案）、`style`（配色）、`keywords`（搜图词）、`hook`（记公式名）。

---

## 十个公式

### 1. 身份围观式
> 「让大家感受下 + [具体身份] + 的[日常/工作状态]」

对标原文：让大家感受下 / **大厂Agent工程师的** / 工作状态

打的是窥探欲。身份越具体越好——"大厂 Agent 工程师"远好过"AI 从业者"。
- 分行：钩子词起手作 sub，身份作 hero，收尾作 sub
- 配色：`yellow` + `block`
- 搜图：该身份的真实工作环境

### 2. 圈层喊话式
> 「我劝所有[身份] + [尽早/别再][动作]」

对标原文：我劝所有程序员 / **尽早布局AI大模型**

打的是身份认领 + 紧迫感。"我劝"这两个字是钩，别换成"建议"。
- 分行：喊话作 sub，动作作 hero
- 配色：`green_inv` / `blue`
- 搜图：该圈层的集体场景（办公区、教室、工位排）

### 3. 焦虑对立式
> 「淘汰你的从来不是[远处的威胁] + 而是[近处的同类]」

对标原文：淘汰你的从来不是AI / **而是会AI的同行**

金句结构，转折在第二行。威力来自"威胁离你更近"。
- 分行：前提作 sub，反转作 hero
- 配色：`magenta` / `red` + `scrim`
- 搜图：空工位、格子间、加班场景

### 4. 进度日记式
> 「[身份]做[事] + 第 N 天 / 第 N 期」

对标原文：**女生下班做AI漫剧** / **90后 第45天**

打的是连载追更。数字必须具体，"第 45 天"比"坚持了一个多月"强。
- 分行：两行都 hero，两端对齐
- 配色：`yellow`
- 搜图：出租屋书桌、笔记本、夜晚台灯

### 5. 低门槛承诺式
> 「[身份]的[出路/机会] + 在家/零基础就能搞」

对标原文：**中年人的AI出路** / 在家就能搞

前半制造身份焦虑，后半立刻卸掉门槛。两半缺一不可。
- 分行：身份+机会作 hero，门槛作 sub
- 配色：`green`
- 搜图：家庭书房、居家办公桌

### 6. 成本揭底式
> 「[某件事] + 真实成本 / 我花了多少钱」

对标原文：**AI视频制作** / **真实成本**

打的是信息差。"真实"两个字在暗示"别人没告诉你的"。
- 分行：两行都 hero
- 配色：`yellow` / `cyan`
- 搜图：设备桌搭、多屏工作站

### 7. 否定替代式
> 「[大家都在做的事]没用 + [新做法]才靠谱」

对标原文：失业焦虑没用 / **用AI动手变现才靠谱**

先否定一个共识动作，再给替代。注意否定的必须是"动作"，不是"人"。
- 分行：否定作 sub，替代作 hero
- 配色：`red` / `yellow`
- 搜图：咖啡馆办公、笔记本+笔记本电脑

### 8. 效果夸张式
> 「[工具/方法] + 强到可怕 / 建议收藏」

对标原文：**AI提效** / 强到可怕 建议收藏

hero 行极短（2–4 字），靠字号砸。"建议收藏"是明示的收藏钩。
- 分行：短词作 hero（会被拉得很大），评价作 sub
- 配色：`yellow`
- 搜图：温暖居家角落、留白多的场景（hero 字大，需要干净带）

### 9. 情绪见证式
> 「[做成的事] + 我成功了啊 / 我哭了 / 太爽了」

对标原文：**AI+漫剧** / **我成功了啊**

打的是共情。语气词（啊、了）不能省，省了就变成通告。
- 分行：两行都 hero
- 配色：`yellow` / `cyan`
- 搜图：卧室、少女感书桌、有生活气的乱

### 10. 测试分流式
> 「[方向]太多？+ N 道题测出你该选哪个」

对标原文：AI副业方向太多？别慌！百大UP主4道题帮你测出该选哪个

打的是选择困难。数字要小（3–5 道），大了就像作业。
- 分行：困境作 sub，测试承诺作 hero
- 配色：`cyan` / `blue`
- 搜图：显示器上的表格/测试界面、办公桌

## 写文案的四条硬规矩

1. **单行 ≤ 10 个汉字宽**（"AI" 算 1.1 字，英文单字母算 0.55）。
   超了字号会掉到 80 以下，缩略图直接糊掉——这是几何约束，不是风格偏好。
2. **hero 行放结论、冲突、身份**；sub 行放铺垫、限定、语气。搞反就没有钩子。
3. **不写品牌名、栏目名、英文 slogan**。它们进标题和简介，不进画面。
4. **数字优先于形容词**。"第 45 天"打得过"坚持很久"，"4 道题"打得过"几个问题"。

## 一批选题的健康度自检

出完 N 个选题，扫一遍：

- 公式覆盖 ≥ 6 种？（不然是同一条选题的 N 个说法）
- 配色至少用到 3 种？
- 有没有出现两条选题指向同一个动作？（"用 AI 变现" / "AI 副业赚钱" 是一条，不是两条）
- 每条的 `keywords` 都是**能搜到真实生活照**的词吗？
  搜"人工智能"只会出概念插画，得搜"程序员工位""出租屋书桌"这种。
